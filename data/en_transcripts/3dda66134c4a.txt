Data types are the quiet source of most Power Query errors, and they're easier to understand than the name suggests. A data type is just the category A column belongs to, whether that's text, a whole number, a decimal number, a date, a date and time, a percentage, or a simple true or false value. Getting the type right matters more than it looks. Power query gives you type specific transformations and filters, and if a column has no type set, those options sit grayed out because the tool doesn't know what kind of values it's holding. Power query also includes profiling tools that show column quality and how values are distributed, which is a fast way to spot trouble before you build anything on top of the data, there's a catch all type called any. Which is what a column gets when it has no explicit type. Microsoft recommends that you avoid leaving any columns in your finished query, because they push the guessing game downstream to whatever consumes your data. Watch for it. Power query tries to help by detecting types automatically against the database.
