But how does the load balancer actually decide which server gets each visitor? Here's the thing, most people get wrong. Azure load balancer does not use round robin. It doesn't just take turns sending traffic to each server like a schoolteacher calling on students. Instead it uses something called a hash based distribution. Here's how it works. When a request comes in, the load balancer looks at five things. The source IP address, the source port, the destination IP address, the destination port, and the protocol. That's called the five tuple hash. It runs those five values through a mathematical function and gets a number. That number determines which backend server gets the request. The key insight is that this is per flow, not per packet. Every packet in a single connection goes to the same backend server.
