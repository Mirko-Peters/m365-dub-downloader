## FAQ

**Do I need to learn a programming language to use Power Fx?**

No. Power Fx is an Excel-like formula language, so anyone who has written a spreadsheet formula already knows the basic pattern. Instead of placing a formula in a cell, you place it in a control property, such as the Text property of a label, and Power Apps keeps the result updated as values change.

**What is the difference between a property formula and OnSelect in Power Apps?**

A property formula describes what a control should be, while OnSelect runs an action when someone clicks or taps. Text, Visible or Color formulas keep recalculating as the screen updates, for example hiding a button until a request is ready. OnSelect formulas run functions such as Notify to show a message or Navigate to open another screen.

**When should I use a collection instead of saving to a data source?**

Use a collection only for a temporary working list while someone completes a task, such as a shopping cart or safety checklist. Collections and variables are not permanent storage and can be lost if the user closes the app. Records the business needs later belong in a connected data source such as SharePoint or Dataverse.
