## FAQ

**Should I use Copilot connectors or plugins to ground Microsoft 365 Copilot?**

Use connectors for knowledge and plugins for actions. Connectors index content into the semantic index, where it inherits Microsoft 365 compliance controls and Entra ID ACLs. Plugins call live APIs at runtime, which suits creating tickets or updating records. Mature deployments combine both, and the episode recommends building the knowledge layer before adding actions.

**What replaces the deprecated Microsoft Graph Security connector in Power Platform?**

Direct HTTP calls to the Microsoft Graph Security API replace it, using the alerts_v2 and incidents endpoints. The connector was deprecated on April 29, 2026, because its underlying service was decommissioned. The new model is incident-centric with nested alerts and evidence, so filters, downstream schemas and notification templates need redesigning, not just new URLs.

**Why do schema property names matter for Copilot connectors?**

Copilot reads property names and descriptions to interpret indexed data, so business-readable names produce better answers. A field called incident root cause with a clear description guides the model, while cryptic abbreviations get ignored or misused. Set the searchable, queryable, retrievable and refinable flags deliberately, and respect the 128-property and 32-character name limits.
