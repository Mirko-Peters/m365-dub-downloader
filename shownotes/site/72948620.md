## FAQ

**What are the three parts of Azure Sphere?**

Azure Sphere combines a certified microcontroller, a locked-down Linux-based operating system and the Azure Sphere Security Service. The chip includes the Pluton security subsystem for a hardware root of trust and secure boot. The OS isolates applications and limits hardware access. The cloud service authenticates devices, pushes updates and collects failure reports. All three are needed together.

**How does Azure Sphere keep IoT devices updated?**

Microsoft pushes OS security updates directly to every device through the Azure Sphere Security Service, and devices cannot refuse them. The device verifies that each update is signed by Microsoft using its hardware root of trust before installing it. Manufacturers do not need to build or approve patches, and Microsoft commits to at least ten years of support.

**When is Azure Sphere worth using for a device?**

Azure Sphere is worth it when a security breach would cost more than the device itself. That fits long-lived industrial sensors, commercial appliances, smart city infrastructure and healthcare equipment that are hard to update manually. It is overkill for cheap home gadgets, and it ties you to Microsoft's chip, OS and cloud service as a trade-off.
