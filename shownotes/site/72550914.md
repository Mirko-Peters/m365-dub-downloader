## FAQ

**What is Work IQ in Microsoft 365?**

Work IQ is an intelligence layer that sits on top of Microsoft Graph and adds context and memory. The episode describes three layers: data from emails, meetings, files and collaboration signals; a context layer that understands projects and relationships; and a memory layer that keeps a persistent picture of how people and teams actually work.

**Can Work IQ show users files they should not see?**

Work IQ never bypasses existing Microsoft 365 permissions, but it surfaces everything a user can technically access. That means overshared SharePoint sites, old group memberships and broken permission inheritance become visible to agents immediately. The episode therefore calls data cleanup, accurate sensitivity labels and DLP policies prerequisites rather than a later project phase.

**How should you measure success with Work IQ?**

Measure outcomes, not adoption or activity. The episode recommends decision speed, cross-team collaboration quality, context reuse and outcome quality as metrics. Start with one high-value workflow and a pilot team of around 20 people, record baseline numbers such as decision cycle time and rework rate, then check results at 30, 60 and 90 days.
