## Key takeaways

- [Azure](https://www.m365.fm/entity/azure/?utm_source=podcast&utm_medium=shownotes&utm_campaign=azure-open-datasets-simply-explained) Open Datasets is a free catalog of curated public data, such as NOAA weather, holidays, US Census and NYC taxi trips, that Microsoft cleans, stores in Parquet and keeps refreshed in Azure.
- You can load the data with the azureml-opendatasets Python package, register it in Azure Machine Learning, connect Power BI through the Blob Storage connector or query it with Synapse serverless SQL and Databricks.
- The data and its storage are free, but compute, egress and your own storage are not, so keep compute in the dataset's region and sample before you scale.

## FAQ

**Is Azure Open Datasets really free?**

The data itself is free, and Microsoft pays for its storage, but processing it is not. You pay for compute such as VMs, Databricks clusters or Synapse serverless SQL queries, egress when moving data across regions or out of Azure, and any storage you use for your own copies. Keeping compute in the dataset's region avoids egress.

**How do I load Azure Open Datasets in Python?**

Install the azureml-opendatasets package with pip and import a dataset class, such as the NOAA weather data, from any Python environment without an Azure account. You set a start and end date, and the package downloads the relevant files from Azure Storage and returns a pandas DataFrame. In Azure Databricks the same SDK can return Spark DataFrames.

**What kind of data is in the Azure Open Datasets catalog?**

The catalog covers weather, holidays, census and labor data, mobility, public safety, health and ML benchmark sets. Examples named in the episode are NOAA weather, public holidays, US Census, US labor force statistics, NYC taxi trips, San Francisco safety data, the COVID-19 data lake, a diabetes dataset, the Microsoft News Dataset and simulated OJ sales data.
