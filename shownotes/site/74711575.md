## FAQ

**Why does SharePoint have such a bad reputation?**

Mostly because of missing information architecture and intranets built by IT rather than for employees. Marcin Siewnicki describes SharePoint used as one huge bucket for everything, with many versions of the same document and no clear structure. Requirements were gathered once, the portal was delivered, and the feedback loop with employees was broken.

**How can organizations prevent SharePoint and Teams sprawl?**

Start with a simple request process before people create sites or teams. Marcin recommends a basic Microsoft Forms form and SharePoint list asking for a business justification and basic metadata, which works even for a customer with more than 50,000 users. Add periodic checks of whether sites are still used, plus regular permission reviews.

**When should you use Power Automate instead of Copilot?**

Use Power Automate when every run must produce the same result. Copilot is AI, so its output can differ from one day to the next, while a Power Automate flow is defined from the first step to the last. Marcin notes you can still use Copilot inside Power Automate without giving up that control.
