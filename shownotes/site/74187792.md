## FAQ

**What is the difference between Logic App Consumption and Logic App Standard?**

Consumption is pay as you go on a platform managed by Microsoft, while Standard runs on your own service plan with reserved compute. With Consumption you only build workflows but cannot predict the monthly bill exactly. With Standard you also manage capacity, get a designer in VS Code and can use network isolation.

**Should I use built-in or managed connectors in Azure Logic Apps?**

Sonny Gillissen recommends built-in connectors whenever possible, because they run inside the Logic Apps runtime and stay part of your integration. Managed connectors are maintained by Microsoft but always leave your environment. A custom connector fits systems that are not covered yet or APIs you already expose through your own API Management gateway.

**What does Organism as a Service mean for Azure Logic Apps?**

It describes an integration that reacts and responds instead of only running a fixed top-down workflow. With agent loops in Logic Apps, AI can interpret an error such as an overloaded API, decide to wait and retry, or send a business data problem to the business and a technical failure to the technical team.
