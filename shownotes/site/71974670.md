## FAQ

**Why does manual sensitivity labeling fail in large organizations?**

Manual labeling fails because it depends on busy users choosing the right label every time they save a file. The episode cites a 30% adoption rate, leaving about 70% of intellectual property invisible to DLP and conditional access. Users pick speed over security, so classification must move from the person into the infrastructure.

**What is the vulnerability window in Microsoft Purview labeling?**

It is the gap between creating a file and its sensitivity label actually taking effect. Labeling through the Microsoft Graph API is asynchronous, and propagation can take from minutes up to 24 hours. During that time the file has no label, encryption or access restrictions, and Microsoft 365 Copilot could already index it.

**How can prompt injection trick an AI classifier into downgrading a file?**

An attacker hides instructions inside a document telling the classifier to ignore previous rules and label the file as public. A naive intelligence layer obeys, Purview protection is stripped and data leaks. The proposed defense is a secondary, specialized model that audits the primary classifier and falls back to the most restrictive label when they disagree.
