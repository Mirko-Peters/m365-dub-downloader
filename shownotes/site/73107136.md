## FAQ

**Why is traditional antivirus no longer enough?**

Traditional antivirus only catches threats it has already seen, because it compares files against known signatures. Modern attacks often use new or custom malware and move between machines after a breach, which signature scanning cannot see. Defender for Endpoint instead watches device behavior and keeps telemetry so suspicious activity can be detected and investigated.

**Is Defender for Endpoint Plan 2 included in Microsoft 365 E5?**

Yes, Defender for Endpoint Plan 2 is included in Microsoft 365 E5, so E5 customers only need to turn it on. Plan 2 adds the full EDR suite with advanced hunting, automated investigation and six months of telemetry retention. The episode also says Business Premium gives access to Defender for Endpoint.

**How do I get started with Microsoft Defender for Endpoint?**

Start by checking your license, then connect Defender and Intune in both portals so they share data. Next, onboard devices: Windows already has the sensor built in, while macOS, Linux, Android and iOS need the agent. Apply Microsoft's security baselines, then monitor alerts and incidents in the Defender portal.
