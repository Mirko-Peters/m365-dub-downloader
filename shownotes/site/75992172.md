## FAQ

**Why do Entra ID access reviews end up as rubber stamps?**

Reviewers approve everything because the design rewards it. They face hundreds of names with no context, approving costs nothing, and a wrong denial breaks someone's work. The fix is small scopes per package or group, more frequent reviews, inactivity recommendations, a fallback reviewer and auto-apply so a deny decision actually removes the access.

**Which Entra ID Governance features need the add-on license instead of Entra ID P2?**

Lifecycle workflows are the main feature that needs the Entra ID Governance add-on. P2 already covers Privileged Identity Management, basic access reviews and core entitlement management. The add-on brings lifecycle workflows, advanced entitlement management options and smarter review features such as reviewer recommendations. Packaging changes often, so check Microsoft's current licensing page before committing.

**How do lifecycle workflows handle movers who change departments?**

A mover workflow fires when an attribute such as department changes, then assigns the new role's access package and removes the old one. Because packages track what they granted, the whole bundle comes off in one step. Access added to groups by hand outside packages is not seen, so reviews still have to catch it later.
