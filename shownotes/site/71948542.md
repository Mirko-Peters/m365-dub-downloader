## FAQ

**Why is manual red teaming not enough for AI agents in finance?**

Manual testing is too slow and static for stochastic models and multi-turn attacks. By the time a human team finds one vulnerability, the model or attack surface has changed. The episode proposes a continuous gauntlet where an attacker model generates injections against the production defender agent, with adversarial examples fed back into fine-tuning.

**Does using multiple AI models make an agent pipeline safer?**

Not on its own. The episode argues that models sharing training data and similar architectures also share blind spots, so a poisoned document retrieved through RAG can pass from one model to the next, with the second validating the first's error. Diversity only helps inside an adversarial framework that pits different model families against each other.

**What should an audit trail for AI agents contain?**

It should be tamper-evident and record the goal, the retrieved context, the tool calls and the final result of every agentic action. Each tool call should be bound to a know-your-agent credential tied to a human sponsor, so a payment decision can be reconstructed within 60 minutes, as the episode recommends.
