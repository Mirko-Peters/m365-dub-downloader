## FAQ

**What is a golden path in platform engineering?**

A golden path is the simplest, most supported way to complete a common task, with security, compliance and monitoring already built in. It is not the only route, since escape hatches remain for edge cases. The episode suggests it covers about 80% of work, so developers decide about their application while infrastructure decisions are made once.

**Should I choose Bicep or Terraform for Azure infrastructure?**

It depends on your cloud strategy. Bicep is Azure native and supports new Azure features on day zero, while Terraform providers can lag by weeks or months. For Azure-only organizations Bicep is increasingly the default; with genuine multi-cloud needs, Terraform offers one consistent language. Some organizations combine both with clear ownership boundaries.

**How do you measure whether an internal developer platform is working?**

Combine several measures: DORA metrics such as deployment frequency and lead time, developer satisfaction or a platform net promoter score, voluntary adoption of golden paths, time to first deployment, and cost avoidance from fewer tickets and incidents. Access numbers alone mislead, because broad access can hide low actual usage of the platform.
