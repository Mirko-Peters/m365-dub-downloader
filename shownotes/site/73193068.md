## FAQ

**What is Microsoft Entra Privileged Identity Management (PIM)?**

Entra PIM provides just-in-time access to Entra ID roles, replacing persistent admin permissions with roles activated only when needed and for a limited time. Mark Orr recommends elevating the least powerful role that fits the task, such as group administrator instead of global admin, deactivating it when done, and capping activations at four hours.

**Why should PIM activations require MFA through authentication context?**

Without authentication context, MFA is satisfied once and the token carries over, so later role activations trigger no new challenge. Mark Orr calls this a common deployment mistake. Tying authentication context to a Conditional Access policy forces admins to prove their identity, for example with a YubiKey, on every elevation, even if credentials are stolen.

**What license do you need for Microsoft Entra PIM?**

Entra PIM requires a Microsoft Entra ID P2 license, an additional cost that Mark Orr does not consider prohibitive. Through a CSP it is billed per user, while EA customers should work with their reseller. He notes that P2 is included with E5 and that E3 customers may be able to negotiate step-up pricing.
