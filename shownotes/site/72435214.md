## FAQ

**What is a multi-agent system?**

A multi-agent system splits one overloaded agent into specialized agents coordinated by an orchestrator agent. David compares it to moving from a monolith to microservices: in his e-commerce example, separate agents handle orders, the shopping cart and the product catalog, which makes each one easier to test, optimize and reuse across projects.

**When should you choose Copilot Studio or Microsoft Foundry for agents?**

Choose Copilot Studio when you already have Power Platform licensing, Copilot Studio credits and data in Dataverse, and performance demands are moderate. Choose Foundry when data lives in Azure, performance needs are higher or orchestration patterns are complex. For fully custom orchestration, David recommends the Microsoft Agent Framework, which works best with Foundry.

**How can you estimate the cost of a Copilot Studio agent?**

Only roughly, because cost depends on real usage, such as how many tools each query triggers. David uses Microsoft's estimator and the documentation's credit tables for first figures, measures credit consumption during testing, then monitors the first month in production and adjusts between credit packs and pay-as-you-go based on what he sees.
