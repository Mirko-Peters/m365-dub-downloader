## FAQ

**What is the difference between public and private DNS zones in Azure?**

Public zones answer queries from the internet, while private zones resolve only inside linked Azure virtual networks. A public zone needs a domain you own and delegation at your registrar. A private zone can use any name and only needs a virtual network link, which can span multiple virtual networks across regions.

**How do I move my domain to Azure DNS without downtime?**

Create the zone in Azure and recreate every existing record before you change the name servers at your registrar. Once delegation switches to the four Azure name servers, records at the old host stop answering. Propagation usually takes minutes but can take up to 48 hours because resolvers cache old information.

**What is an alias record in Azure DNS?**

An alias record points a DNS name directly to an Azure resource instead of a static IP address. If a load balancer, CDN endpoint or Traffic Manager profile gets a new IP, the record updates automatically. With a regular A record you would have to change the DNS entry manually every time.
