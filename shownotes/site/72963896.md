## FAQ

**What is PowerShell used for?**

PowerShell is an automation platform that combines a command-line shell, a scripting language and a remote management tool. Admins use it to manage Windows, Azure, Microsoft 365, Exchange, Teams, SharePoint, Active Directory and even Linux machines with the same commands, and PowerShell 7 runs on Windows, Linux and macOS.

**How do I find PowerShell commands without memorizing them?**

Use the three discovery cmdlets: Get-Help, Get-Command and Get-Member. Get-Help shows syntax, parameters and working examples for any command, Get-Command lists what is available, for example every command with the noun Service, and Get-Member reveals the properties and methods of the objects a command returns.

**What is the PowerShell pipeline?**

The pipeline passes the objects one cmdlet outputs directly into the next cmdlet as structured data. You get something, filter it with Where-Object, shape it with Select-Object or Sort-Object, act on it and export it, for example with Export-Csv. The same pattern works for one user or a thousand.
