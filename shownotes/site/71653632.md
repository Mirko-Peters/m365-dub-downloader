## FAQ

**Why does Microsoft 365 Copilot give confident but wrong answers about project status?**

Copilot often sees only documents in SharePoint and OneDrive, not the live state of other systems. A pending approval in a procurement tool, a critical support ticket or a budget freeze in the ERP stays invisible, so the answer sounds structured and professional while missing the context that actually decides the outcome.

**Is integrating a CRM with Outlook the same as indexing it for Copilot?**

No, integrated is not the same as indexed. An integration may display a CRM record inside Outlook, but the AI can only reason across that data once it lives in the semantic index. Custom connectors put CRM, ticketing and delivery data into the graph so Copilot can see conflicts like an open support crisis.

**How should permissions be handled when building a custom Graph connector?**

The connector must replicate source permissions exactly through access control lists, so users never see records in Copilot that they cannot open in the original system. That requires mapping external user identities to Microsoft Entra ID before data moves, and relying on Entra ID entitlements so every query is trimmed in real time.
