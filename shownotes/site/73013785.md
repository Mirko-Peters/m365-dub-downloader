## FAQ

**What is the difference between Azure AI Foundry and Microsoft Foundry?**

They are the same product under different names. The platform started as Cognitive Services, then became Azure AI Services, Azure AI Studio, Azure AI Foundry and finally Microsoft Foundry. The episode notes that two versions run side by side at the same URL: the classic hub-based architecture and the newer Foundry project model.

**Should I use hubs or Foundry projects when starting with Foundry?**

Start with Foundry projects and skip hubs. Hubs still work and are supported, but new capabilities such as the agent playground, the agent service and memory only come to Foundry projects. Following an old hub tutorial can leave you with a setup that cannot use the latest tools, which is a common beginner trap.

**What components does an agent in Microsoft Foundry need?**

A Foundry agent combines five components: instructions, a model, tools, knowledge and memory. Instructions act like a job description, the model is the brain, and tools such as web search, code interpreter and file search let it act. Knowledge comes from uploaded documents indexed by Azure AI Search, and memory keeps preferences across conversations.
