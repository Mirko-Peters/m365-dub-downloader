## FAQ

**Why does my Azure Load Balancer health probe show backends as unhealthy?**

Most often a network security group blocks the probe traffic from the Azure IP 168.63.129.16. The episode's checklist also covers a probe protocol or port that does not match the application, route tables that send probe packets elsewhere, and testing the application directly from another VM in the same network.

**Does Azure Load Balancer use round robin?**

No, Azure Load Balancer uses a hash-based distribution instead of round robin. It hashes the five-tuple of source IP, source port, destination IP, destination port and protocol, and routes per flow, so every packet of one connection reaches the same backend. Session persistence is off by default and should only be enabled when needed.

**When should I use Azure Load Balancer instead of Application Gateway or Front Door?**

Use Azure Load Balancer for non-HTTP traffic and simple layer 4 distribution within one region. Application Gateway suits web apps in one region that need URL routing, SSL termination or a web application firewall. Front Door or Traffic Manager handle global distribution, with Traffic Manager working at the DNS level.
