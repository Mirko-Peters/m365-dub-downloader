## FAQ

**What are the five services in Azure DevOps?**

Azure DevOps consists of Azure Boards for planning and tracking work, Azure Repos for Git version control, Azure Pipelines for build and deployment automation, Azure Test Plans for structured and manual testing, and Azure Artifacts for sharing packages. Each does its own job, but they link work items, code, builds and tests together.

**Is Azure DevOps free to use?**

Yes, Azure DevOps has a free tier. According to the episode, five users get full access and unlimited stakeholders get limited access at no cost, with no credit card required. You create an account at dev.azure.com, start a project and can use the core features before deciding whether to pay.

**How does Azure DevOps link code to work items?**

Developers include the work item ID in commit messages or create branches from a work item, which links commits and pull requests to items in Azure Boards. Failed test cases in Azure Test Plans create linked bugs, so you can trace a user story through code, pipeline runs and tests.
