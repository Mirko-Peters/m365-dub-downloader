## Key takeaways

- Microsoft Entra Cloud Sync moves most identity sync processing into Microsoft Entra, leaving only lightweight provisioning agents in the local network that connect outbound to the cloud.
- Multiple agents provide built-in failover and can connect separate Active Directory forests to one tenant, while scoping by OU or security group and provision on demand keep pilots controlled.
- Entra Connect still fits setups with pass-through authentication, federation, advanced custom rules or specific [Exchange](https://www.m365.fm/entity/exchange-online/?utm_source=podcast&utm_medium=shownotes&utm_campaign=microsoft-entra-cloud-sync-simply-explained) hybrid needs, so compare requirements before migrating and never let both tools manage the same objects.

## FAQ

**What is the difference between Microsoft Entra Cloud Sync and Entra Connect?**

Cloud Sync runs most sync processing in Microsoft Entra, while Entra Connect runs a full sync engine on a local server. Entra Connect keeps local rules and its own data store, so someone must patch and troubleshoot that server. Cloud Sync only needs small provisioning agents that connect outbound, with configuration managed in the Entra portal.

**When should I keep Entra Connect instead of moving to Cloud Sync?**

Keep Entra Connect when you rely on pass-through authentication or federation, advanced custom sync rules, or Exchange hybrid needs that Cloud Sync does not cover. The episode notes that Exchange hybrid attribute writeback is only in public preview, so test with non-production accounts and check current Microsoft documentation before moving anything.

**Does Cloud Sync support high availability and multiple Active Directory forests?**

Yes. You can install more than one provisioning agent in the same domain, and if one goes offline Microsoft Entra uses another healthy agent. For separate forests, for example after a merger, you place an agent near each forest and all agents connect outbound to the same tenant, with no direct network path between forests required.
