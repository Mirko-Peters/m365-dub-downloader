## FAQ

**What are the most common mistakes beginners make in Power BI?**

The most common mistake is pulling data straight into reports without checking data quality first. Krishnakanth recommends fixing errors and wrong data types in Power Query or at the source, then modeling clean relationships between dimension and fact tables, with cross-filter direction flowing from dimension to fact, before building any visuals.

**When should I use Power Query and when should I use DAX?**

Use Power Query, or ideally the data source itself, for shaping data and creating columns, and DAX for metrics. Power Query handles transformations such as unpivoting, appending similar tables and merging on a common column. DAX is for key measures and trends like year over year or month over month, shown in card or KPI visuals.

**How do you find out why a Power BI report is slow?**

Start with Performance Analyzer to see how long each visual takes to load. For the slowest visuals, check the underlying columns and data at the source, then decide whether to switch storage mode, for example from import to DirectQuery. For very large datasets, the guest suggests live connections, for example to Azure Analysis Services.
