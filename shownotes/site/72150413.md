## FAQ

**Why is syncing SharePoint libraries with OneDrive a security risk?**

Syncing replicates enterprise data onto endpoints instead of keeping it in the service. Local copies lose SharePoint metadata and real-time co-authoring, create conflict duplicates, and sit outside real-time protections like data loss prevention. On unmanaged devices, a compromised identity or local admin can harvest the synced cache without ever attacking SharePoint itself.

**What happens when a user deletes a OneDrive shortcut to a SharePoint library?**

According to the episode, deleting a folder that is a shortcut to a shared SharePoint library can propagate to the source, removing the files for everyone rather than just the link. Because shortcuts sit inside personal OneDrive, users lose the boundary between their own and team content, so training and governance are needed.

**How many items can OneDrive sync from a SharePoint library?**

The episode puts the practical ceiling at about 300,000 items, measured by item count rather than gigabytes. Beyond that, the sync client spends heavy CPU reconciling metadata and can stall. Shortcuts are said to support up to 500,000 items, but adding a shortcut to a library that is already synced causes a silent conflict.
