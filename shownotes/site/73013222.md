## FAQ

**What is Microsoft Purview?**

Microsoft Purview is a family of solutions that protects data itself rather than only the infrastructure around it. It rests on three pillars: data governance to know what data you have, data security to protect it with sensitivity labels and DLP, and data compliance to prove to regulators that you follow the rules.

**How does Microsoft Purview protect data used by Copilot?**

Purview extends its existing controls to AI interactions. DLP policies scan prompts and responses, summaries inherit the sensitivity label of their source document, and data security posture management for AI flags oversharing. The AI hub shows which AI apps are used, and prompts and responses can be retained for audits.

**Where should I start with Microsoft Purview?**

Start by running a data classification scan to see what sensitive information already exists. Then focus on the biggest risks, such as financial, medical and personal data, pilot sensitivity labels with a small group, run DLP policies in simulation mode before enforcing them, and use Compliance Manager as a roadmap for your regulations.
