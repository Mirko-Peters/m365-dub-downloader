## FAQ

**Can Azure SQL Database call external REST APIs?**

Yes, Azure SQL Database can call external REST APIs with sp_invoke_external_rest_endpoint. Dirceu Resende uses it to score customer feedback with AI, clean messy imported data, send email through an API, post alerts to messaging tools or create tasks in a CRM. He notes Azure SQL had this years before SQL Server 2025 brought it on-premises.

**How should API credentials be stored in Azure SQL Database?**

Store them in a database credential object created by an admin, not inside every procedure. Procedures then reference the credential, so developers never see the token or password. When a token expires, the admin updates one credential and every procedure using it works again. Bearer tokens, user and password, and API key headers are supported.

**When should you choose Azure SQL Managed Instance instead of Azure SQL Database?**

Choose Managed Instance when you need cross-database queries, SQL Server Agent or SQL CLR procedures written in .NET, because it behaves much like on-premises SQL Server. Azure SQL Database works on single, independent databases with their own capacity and pricing, which Dirceu recommends especially for microservices that should not share resources.
