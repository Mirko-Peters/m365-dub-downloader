## FAQ

**Why do enterprise AI agents need Microsoft Graph?**

Agents need Microsoft Graph because an LLM alone knows nothing about your organization and guesses, which causes costly hallucinations. Graph supplies organizational context such as who works with whom, how decisions flow and which data is sensitive, so agents can reason about your actual business and act through governed tool calls instead of producing plausible guesses.

**What is the supervisor agent pattern and how does it work?**

It is a design where one orchestrating agent coordinates narrow specialist agents instead of one agent doing everything. In the episode's HR example, a supervisor invokes sourcing, compliance and scheduling agents in order, using shared state, checkpoints and explicit handoffs, so every decision is logged and escalations to humans are auditable.

**Which agent actions should require human approval?**

Actions involving money, deletion of information, or anything leaving the organization should require human approval. Routine, reversible tasks such as reading email or scheduling internal meetings should not. The episode recommends threshold-based approval ranges and evidence packs, so a reviewer sees the data and rules the agent used and can decide in seconds.
