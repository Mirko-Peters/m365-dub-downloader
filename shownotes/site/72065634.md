## FAQ

**What is the biggest misconception about DAX?**

The biggest misconception is that DAX works like Excel. Bernat says DAX is nothing without the data model, and that he also struggled at first with the difference between measures and columns. He recommends investing time in modeling basics and reading the definitive guide to DAX instead of trying to google your way through.

**Why use Tabular Editor instead of Power BI Desktop for large models?**

Tabular Editor works offline on the model metadata, so developers can edit many measures quickly without waiting for Power BI Desktop to validate each change. Bernat highlights access to all object properties, a powerful DAX editor with shortcuts, and C# scripting, which he authors in Visual Studio and pastes into Tabular Editor.

**How do DAX user-defined functions compare to calculation groups?**

DAX user-defined functions centralize code without the extra filter context and trade-offs that calculation groups bring. Their drawback is that you must create every measure with the right names and properties. Bernat wrote a C# script that reads annotations on the functions and generates those measures automatically, so the measures stay usable on their own.
