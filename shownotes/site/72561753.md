## FAQ

**What is the difference between Microsoft Agent 365 and Foundry Agent Service?**

Agent 365 is the governance plane that discovers and governs agents, while Foundry Agent Service is the runtime where they execute, keep state and call tools. According to the episode, Agent 365 reached general availability on May 1, 2026 and Foundry Agent Service in March, so governance and runtime now work together.

**Why should every AI agent have its own Microsoft Entra Agent ID?**

Its own identity lets an agent get least-privilege access, follow Conditional Access policies, appear in access reviews and log every action under its own name. Instead of using a shared service account, the agent requests short-lived tokens, secrets stay in Azure Key Vault, and revoking the identity stops a compromised agent immediately.

**When should you move an agent from Copilot Studio to Microsoft Foundry?**

Move it once the pilot works, people actually use it and it measurably reduces work. The episode calls Copilot Studio the place to prototype and Foundry the place to operate, adding orchestration, memory across sessions and multi-agent capabilities. Before that, ground the agent in your data, pilot it with a small team and register it in Agent 365.
