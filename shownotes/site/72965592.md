## Key takeaways

- The [Dynamics 365](https://www.m365.fm/entity/dynamics-365/?utm_source=podcast&utm_medium=shownotes&utm_campaign=dynamics-365-erp-mcp-server-simply-explained) ERP MCP server exposes finance and operations functions to AI agents through one governed interface, and the dynamic version lets agents work through forms, including customizations and ISV extensions.
- The analytics MCP server on Business Performance Analytics needs only two tools, get dataset schema and execute DAX query, and combining it with the action server turns insights into ERP actions.
- Agents inherit the connected user's Dynamics 365 security, but the preview has limits such as a 120-second timeout, so start with low-risk tasks and keep a human in the loop for high-risk actions.

## FAQ

**What is the difference between the static and dynamic Dynamics 365 ERP MCP server?**

The static server offered a fixed set of 13 tools, while the dynamic server lets agents work through ERP forms like a human user. With the dynamic version, now in public preview, agents open forms, set fields, click buttons and run actions under the same business logic, and customizations and ISV extensions become visible automatically.

**What do I need to try the Dynamics 365 ERP MCP server?**

You need a Dynamics 365 Finance and Operations environment on version 10.0.38 or higher and an MCP-compatible client. For the analytics server you also need Business Performance Analytics version 2.5 or later. The easiest client is Copilot Studio, where you add the ERP MCP tool to an agent; VS Code works for more technical testing.

**Can an AI agent bypass Dynamics 365 security through MCP?**

No, the agent uses the security permissions of the connected user identity. Role-based access you have set up in Dynamics 365 applies automatically, so an agent cannot see other legal entities or post journals if the user cannot. The episode still recommends a human in the loop, monitoring and audit trails for high-risk actions.
