## Key takeaways

- Traditional VPNs start with the network and often grant broader reach than a user needs, which increases the risk of lateral movement and adds routing and support overhead.
- Microsoft Entra Global Secure Access puts identity at the center: Entra ID and [Conditional Access](https://www.m365.fm/entity/conditional-access/?utm_source=podcast&utm_medium=shownotes&utm_campaign=global-secure-access-simply-explained) decide, per request, whether a user on a given device may reach a specific private app or internet destination.
- Entra Private Access replaces broad VPN tunnels with app-specific routes via connectors, while Entra Internet Access applies web, SaaS and AI traffic rules that follow the user anywhere.

## FAQ

**Is Global Secure Access just a new VPN?**

No. Microsoft Entra Global Secure Access is a cloud-based security service edge that grants access per destination rather than to a network segment. Entra ID and Conditional Access check the user, device and requested app or website, then traffic flows through Private Access or Internet Access instead of one broad tunnel.

**How does Entra Private Access reach on-premises apps?**

Through connectors. A connector runs inside the company network close to the private apps and creates an outbound connection to the Global Secure Access service, so the app needs no public front door. Users then get a controlled path to one specific app, such as a project tool, rather than a whole network segment.

**Can Entra Internet Access stop uploads to unapproved AI tools?**

Yes, with network file filtering and Microsoft Purview. In the episode's example, an employee drags a planning document into an unapproved AI app; if the file matches a policy, the upload is blocked before it reaches the service. This content check relies on TLS inspection of selected encrypted traffic under the organization's policy.
