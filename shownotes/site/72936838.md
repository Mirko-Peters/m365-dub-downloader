## FAQ

**How is Copilot in Microsoft Fabric different from Microsoft 365 Copilot?**

Copilot in Fabric works only on data and analytics inside Microsoft Fabric, while Microsoft 365 Copilot helps with documents, emails and meetings. The episode compares them to specialists: Microsoft 365 Copilot writes reports, GitHub Copilot builds software, and the Fabric version handles data work such as queries, pipelines, notebooks and Power BI reports.

**What do I need to turn on Copilot in Microsoft Fabric?**

You need a paid Fabric capacity, F2 or higher according to the episode, and a Fabric admin who enables Copilot in the tenant settings. There is no extra license beyond the capacity. If the Copilot icon is missing, the setting is probably not enabled yet, so the advice is to talk to your admin.

**Can Copilot in Fabric see data I don't have permission to access?**

No, Copilot only works with data you already have access to and respects your existing permissions. If you cannot see a table in the warehouse or a semantic model, Copilot cannot query it either. It does not bypass security controls, but it also will not fix a broken data model or poorly designed access structure.
