## FAQ

**Is PnP PowerShell developed and supported by Microsoft?**

No. PnP PowerShell is fully open source and maintained by community volunteers in their spare time, and Microsoft does not support it. Gautam calls this the most common misconception, noting that Microsoft support sometimes redirects people to the maintainers. Contributions come through GitHub issues and pull requests, which the team reviews before merging.

**Why use PnP .NET instead of calling Microsoft Graph directly?**

PnP .NET offers a fluent API wrapper around Microsoft Graph plus robust throttling and error handling. When an application sends very large volumes of requests, Graph throttles them, and the library handles those cases gracefully. It also exposes configuration options, for example slowing requests as a SharePoint resource quota is approached.

**What is the difference between an AI assistant and agentic AI in GitHub Copilot?**

An AI assistant keeps a human in the loop: Copilot suggests changes, and the developer creates the pull request and tests it. Agentic AI covers the whole cycle: you assign an issue, the agent creates a branch, implements and tests the change, and opens a pull request, depending on the permissions granted.
