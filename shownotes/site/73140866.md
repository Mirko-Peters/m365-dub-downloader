## FAQ

**Who needs Microsoft Partner Center?**

Any business that builds on, resells or consults around Microsoft products needs Partner Center, not only large resellers. That includes direct bill partners, indirect providers and indirect resellers in the CSP chain, and also a small consultancy or managed service provider with a few Microsoft 365 clients that wants its benefits and incentives.

**What do the Launch, Core and Expanded partner benefit tiers include?**

Launch includes five users each of Microsoft 365 Business Premium and Teams Enterprise, $700 in annual Azure credits and Visual Studio Enterprise. Core adds more licenses, more flexible use of Azure credits and premium support incidents. Expanded adds Microsoft 365 Copilot, Copilot Studio, Defender for Business, Entra ID premium, Intune and more Azure credits.

**What Partner Center API changes do partners need to prepare for?**

Partners automating Partner Center must make their API calls MFA-ready, because by April 2026 every app plus user call needs a multifactor authentication token. The episode also covers the move to an asynchronous billing API on Microsoft Graph, a customer agreement attestation API, and replacing old graph.windows.net tokens with api.partnercenter.microsoft.com.
