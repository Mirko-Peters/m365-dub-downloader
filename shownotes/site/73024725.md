## FAQ

**What is Azure NetApp Files?**

Azure NetApp Files is a first-party, fully managed Azure file storage service built on NetApp technology. It supports SMB and NFS, even on the same volume, and targets workloads that need sub-millisecond latency and very high throughput. You create a volume, pick a performance tier and start using it, without patching servers or replacing hardware.

**What is the difference between Azure NetApp Files and Azure Files?**

Azure NetApp Files is built for peak performance, while Azure Files is optimized for cost. The episode cites up to 450,000 IOPS per volume versus 100,000 per Azure Files premium share, sub-millisecond latency, no per-file throughput caps and volumes up to two petabytes. Azure Files remains the better choice for general department shares and cost-sensitive workloads.

**What does the flexible service level in Azure NetApp Files do?**

The flexible service level decouples capacity from throughput, so you set storage size and performance separately. Previously, a one terabyte database needing high throughput could require 64 terabytes on the standard tier. Now you pay for what you need, scale throughput up for peaks or failover, and back down after a 24-hour cool-down. It was in preview when recorded.
