## FAQ

**What is AI-native fusion development in Power Platform?**

AI-native fusion development is the third generation of Power Platform, where AI joins the fusion team of business experts, makers, developers, architects and administrators. Reza Niroomand says it does not eliminate roles but changes how people spend their time: makers describe outcomes, developers focus on architecture, and architects define boundaries for agents.

**What should be stored in Git for a Power Platform project?**

Git should hold everything that is designed or built as source, but not build outputs. Plug-in assemblies, NuGet packages and other compiled artifacts belong elsewhere. Reza Niroomand argues the repository should be enough to spin up a development environment and deploy everything, not just serve as a history for traceability.

**What are XRM Tools and PSDataverse used for?**

XRM Tools brings plug-in and custom API registration into code inside Visual Studio, while PSDataverse moves large data volumes in and out of Dataverse with PowerShell. XRM Tools uses C# attributes, so registration sits beside the business logic. PSDataverse runs parallel, batched pipelines and is designed to resume after failures such as network outages.
