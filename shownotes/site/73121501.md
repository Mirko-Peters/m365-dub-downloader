## FAQ

**What is Real-Time Intelligence in Microsoft Fabric?**

Real-Time Intelligence is a set of Fabric tools for ingesting, analyzing, visualizing and acting on data the moment it arrives. It packages proven Azure technology into eventstreams, Eventhouse, real-time dashboards and Activator. Because it runs inside Fabric, it connects to OneLake and shares the same security and governance as other workloads.

**When do I need real-time analytics instead of batch processing?**

You need real-time when an action must happen within seconds of the data arriving, such as stopping an overheating machine or blocking a fraudulent card payment. Monthly sales reports, quarterly reviews and campaign analysis work fine with nightly batch refreshes. Batch is often cheaper because compute does not run continuously, so many teams combine both approaches.

**What is the difference between a real-time dashboard and a Power BI report?**

A real-time dashboard is built directly on Eventhouse and updates continuously as events arrive, with no refresh cycle. Power BI reports refresh on a schedule or use DirectQuery and are meant for deeper analysis over time. Real-time dashboard tiles are created from KQL queries, and the episode suggests using both tools for different purposes.
