## FAQ

**What is an invisible employee in IT support?**

An invisible employee is an autonomous agent inside Microsoft 365 that watches for changing conditions instead of waiting for a prompt. It has its own identity, a defined scope, memory of past actions and strict rules about what it can touch, and it fixes drift such as sign-in, license or sharing problems before a ticket exists.

**How should AI support agents be governed in Microsoft 365?**

Govern them like employees: each agent needs its own identity in Microsoft Entra, a named owner, a defined scope, least-privilege permissions and a lifecycle with a planned retirement. High-impact actions should pause for human approval, reasoning and actions should be logged, and rollback paths must exist before the first autonomous action goes live.

**How do you measure the ROI of autonomous IT support?**

Measure outcomes rather than ticket volume: autonomous resolution rate, reduction in mean time to resolution, cost per resolution and regained user productivity. The episode cites research putting human handling at about $8.75 per issue versus under $0.50 for narrow agentic handling, while warning that rework and weak telemetry can inflate the numbers.
