## FAQ

**What is the difference between delegated and app-only permissions in Microsoft Graph?**

Delegated permissions let an app act on behalf of a signed-in user, such as an app reading your calendar. App-only permissions give the application its own identity, which suits background services and scripts running without a user. Either way, each scope must be requested explicitly, and broad scopes need admin consent.

**Can I use Microsoft Graph without being a developer?**

Yes. Power Automate offers prebuilt connectors that call Graph for you, and it can send custom HTTP requests to any Graph endpoint copied from the documentation. Power Apps can show live user profiles, org charts and SharePoint file data, and Graph Explorer lets you test queries against your tenant in a browser.

**Why should I move from Exchange Web Services to Microsoft Graph?**

Because EWS is being retired and new features only arrive in Graph. The episode notes that by October 1, 2026, calendar interoperability with services like Google Workspace moves entirely to Graph, and after December 31, 2026, changing sensitive properties on received mail requires a new advanced permission with admin consent.
