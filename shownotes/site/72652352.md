## FAQ

**What is the agentic developer stack?**

The agentic developer stack is a model of four connected agent layers: orchestration through Copilot CLI, transformation through modernization agents, validation through code review agents and execution through cloud coding agents. The layers pass work through structured handoffs and shared project memory, while humans set policy, define guardrails and make the final decisions.

**How is Copilot CLI different from the GitHub Copilot coding agent?**

Copilot CLI works synchronously on your local machine, so you watch it plan and run tasks in the terminal with feedback in seconds. The coding agent works asynchronously: you assign it a GitHub issue, it clones the repository into an ephemeral cloud environment, runs tests and security scans, and opens one pull request for review.

**Why does cross-model review improve AI-generated code?**

Cross-model review helps because different model families fail in different ways, so a reviewer from another family catches blind spots the generating model would repeat. The episode calls this the rubber duck protocol in Copilot CLI and cites research where a mid-tier model paired with a reviewer from another family closed nearly 75% of the gap to a top-tier model.
