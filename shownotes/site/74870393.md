## FAQ

**Do developers still need to write code when AI agents generate most of it?**

Yes, developers are still needed, but their role is changing. Andre Baltieri says agents now write most of his code, yet someone must understand the business rules, give the AI good context and have the technical background to ask the right questions. Developers increasingly review, validate and orchestrate agents instead of typing every line by hand.

**What does Microsoft Agent Framework add over calling an AI model API directly?**

It removes a lot of integration code. Microsoft Agent Framework gives .NET developers one interface to several models, plus support for MCP servers, RAG and data ingestion. Andre explains that it combines Semantic Kernel and AutoGen, and that a single line of code can expose an existing C# method to AI as an MCP function.

**How should you secure AI agents that can call your application's functions?**

Apply least privilege and expose only what is needed. Andre recommends a security layer in front of the models, for example permissions through Microsoft Entra ID in Azure AI Foundry, and small purpose-built functions instead of broad ones, such as a product list that leaves out unreleased items. System prompts and guardrails help limit prompt injection.
