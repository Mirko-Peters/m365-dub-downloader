## FAQ

**What is Azure API Management used for?**

Azure API Management is a managed service that sits between backend APIs and the apps, devices and partners that consume them. It covers the full API lifecycle, from publishing and securing to monitoring and retiring, through three parts: the gateway that handles requests, the management plane for configuration and a self-service developer portal.

**What are policies in Azure API Management?**

Policies are rules that change request or response behavior at the gateway without touching backend code. They run at four points: inbound, backend, outbound and on-error. Typical uses include validating JWT tokens, rate limiting, IP filtering, caching, rewriting URLs and transforming responses, with custom C# expressions available for more advanced logic.

**Which Azure API Management pricing tier should I choose?**

Use the developer tier for testing, standard for most production workloads and premium for global scale or private networking. Consumption bills per call with no fixed monthly cost, developer costs around 50 dollars a month without an SLA, and premium starts around 2,700 a month per unit. You can migrate tiers later.
