## FAQ

**What are code apps in Power Apps?**

Code apps let you build a Power App with a code editor such as Visual Studio Code, either writing code by hand or vibe coding it. Keith Atherton says they became generally available early this year and still follow your governance model and sign-in. His wish is a prompt-based start, because command-line setup intimidates non-technical makers.

**Why does testing matter more when AI writes Power Apps code?**

Because nobody wrote the code by hand, testing is the only real proof that it works. Keith has seen vibe-coded websites where registration or password reset failed because testing was skipped. He suggests a test-driven approach and expects future work to shift from development toward validating results and stating business requirements clearly.

**How can organizations let citizen developers build safely?**

Use governance tools such as data loss prevention policies to define which connectors people may use, for example Dataverse and SharePoint lists but not Google Drive. Keith recommends separate development environments, training and coaching so non-technical staff can experiment safely, and warns that banning tools outright tends to create shadow IT or shadow AI.
