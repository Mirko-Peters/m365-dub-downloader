## FAQ

**Which Conditional Access policies should every Microsoft 365 tenant have?**

Jonathan Hope recommends six foundation policies: MFA for all users, MFA with a phishing-resistant method for admin roles, blocking device code flow, blocking legacy authentication, and a two-step set of allowed-country controls. They need only a P1 license rather than Intune and are meant to stop the low-hanging attacks.

**Why use Bicep instead of documenting Azure deployments in the portal?**

Because the Azure portal changes faster than click-by-click documentation can follow. Jonathan's portal guide of more than 120 pages was outdated by the second client, while Bicep, being desired-state and idempotent, let him redeploy the same secure baseline repeatedly and cut a three-day build to roughly four to six hours.

**Are security defaults enough to protect a Microsoft 365 tenant?**

No. Jonathan calls the idea that security defaults are secure by default the biggest security myth, because Microsoft favors collaboration when security would hinder it. Security defaults try to enforce MFA for everyone but fall short, so he recommends deliberate Conditional Access policies and removing weak methods such as email, TOTP and SMS.
