## FAQ

**What is the difference between delta queries and change notifications in Microsoft Graph?**

Change notifications push an event to your endpoint when something changes, while delta queries return only what changed since your last delta token. The episode recommends combining them: subscriptions for immediacy, delta tokens for precision. Together they replace fragile polling scripts with a near real-time change stream, for example to validate new teams against governance rules.

**When should you use Microsoft Graph Data Connect instead of the Graph API?**

Use Graph Data Connect when the question needs organizational scale, such as analyzing collaboration patterns across tens of thousands of users over many months. It is a governed bulk export into Azure destinations like storage or Microsoft Fabric, with admin approval and privacy controls. Interactive Graph calls remain the tool for real-time control and operational automation.

**Why does Microsoft 365 Copilot depend on Microsoft Graph?**

Copilot relies on Graph to find context, enforce permissions and apply security trimming before an answer is returned. The episode argues that Copilot accelerates whatever state your data is in, so clean SharePoint libraries, sensible permissions and governed connectors produce better responses. It also notes the semantic index needs one to two days to build.
