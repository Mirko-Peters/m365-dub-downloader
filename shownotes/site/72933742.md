## FAQ

**What is a Power Apps code app?**

A Power Apps code app is a Power App you build in code instead of a visual designer. Developers write it in Visual Studio Code with JavaScript, TypeScript and React, then deploy it to Power Apps, which handles hosting, authentication and management, so there is no own server or login screen to build.

**What license do users need to run Power Apps code apps?**

Users need a Power Apps Premium license to run code apps, and there is no separate code app SKU. Admins must also turn code apps on per environment in the Power Platform admin center under environment settings, product, features, because the setting is off by default.

**Do DLP policies apply to Power Apps code apps?**

Yes, code apps use the same connectors as canvas apps, so data loss prevention policies apply. If a connector is blocked in an environment, it is blocked in code apps too. Code apps also appear in solutions, deploy through pipelines, inherit environment policies and support conditional access and audit logging.
