## FAQ

**What is the difference between Azure Resource Manager and an ARM template?**

Azure Resource Manager is the control layer that handles every Azure request, while an ARM template is the JSON file it reads to deploy resources. Whether you use the portal, PowerShell, the Azure CLI or a REST API, requests pass through Resource Manager, which authenticates, authorizes and routes them, and also works out dependencies between resources.

**What sections does an ARM template need?**

An ARM template needs only three sections: schema, content version and resources. Parameters, variables and outputs are optional, but most real-world templates use all six. Parameters take values at deployment time, variables hold reusable logic such as naming conventions, and outputs return information like a public IP address or resource ID afterwards.

**How can I check an ARM template before deploying it?**

Run az deployment group validate and the what-if operation before deploying. Validation checks for syntax errors, missing properties and invalid references without creating resources, and what-if shows which resources would be created, modified or deleted. If a deployment still fails, the deployment operations in the portal list error codes and messages for each step.
