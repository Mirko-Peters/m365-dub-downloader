## FAQ

**Why does data governance need to come before an AI rollout?**

Because AI moves bad data faster. A wrong customer status, conflicting revenue figures or a misplaced sensitive file can become a confident decision spread across the organization. Governance names a business owner, documents sources and flows, classifies sensitive data and sets access rules, so someone can answer when an AI output looks wrong.

**What is a semantic layer in simple terms?**

A semantic layer is a shared business dictionary with pre-approved calculations built in. You define a term like active customer once, store the logic once and reuse it in every Power BI report and AI prompt. That stops sales, support and finance from producing reports that each use a different meaning for the same word.

**How can a team test whether its data and AI setup is ready?**

Pick one live report, Copilot prompt or Power Platform flow and run it through five checks: data trust, term alignment, decision impact, safe challenge and ownership. Map the data owner, business definition, decision owner, concern channel and accountable person on one page. Any pillar without an owner shows where to pause automation.
