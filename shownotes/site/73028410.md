## FAQ

**Does Azure Traffic Manager add latency to user requests?**

No, Azure Traffic Manager adds no latency because it never sits in the data path. It only answers the DNS query with the IP address of the best endpoint, then the user connects directly to that endpoint. It does not proxy requests, inspect packets or cache content, and it works with any internet-facing endpoint.

**Which Traffic Manager routing method should I use for disaster recovery?**

Use priority routing for disaster recovery. You rank endpoints, all traffic goes to priority one, and when health probes detect a failure, new users shift to priority two. Existing sessions keep their endpoint until the DNS cache expires, so set a low TTL of 30 to 60 seconds and test that the backup handles full load.

**What is the difference between Traffic Manager, Load Balancer and Front Door?**

Traffic Manager routes users across regions at the DNS level, Azure Load Balancer distributes traffic across VMs within a single region, and Front Door adds global caching, TLS termination and WAF at the edge. Application Gateway provides layer 7 routing and a web application firewall. Traffic Manager works alongside these services rather than replacing them.
