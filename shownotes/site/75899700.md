## FAQ

**What is the difference between merge and append in Power Query?**

Merge makes a table wider and append makes it longer. Merge joins two tables on matching values in one or more columns, like a database join, adding columns such as customer name to an orders table. Append stacks rows from tables with the same columns, for example twelve monthly sales files into one table.

**Why does Power Query show errors when I change a column to date?**

Usually because the file's date format disagrees with your locale. Power Query guesses types from the first two hundred rows of files like CSV, and a date can be written day first or month first. Right-click the column, choose Change Type, then Using Locale, and tell it how the file writes dates.

**Can Excel refresh Power Query on a schedule?**

Not in the way Power BI can. Scheduled refresh is a Power BI and cloud capability, while plain Excel lacks that scheduling switch, so desktop workbooks are refreshed manually or programmatically through Excel's object model. Each refresh reruns all saved steps in order and pulls in additions, changes and deletions without altering the source.
