## Key takeaways

- [Azure](https://www.m365.fm/entity/azure/?utm_source=podcast&utm_medium=shownotes&utm_campaign=azure-service-bus-simply-explained) Service Bus is Microsoft's fully managed message broker that decouples applications so senders and receivers can fail, scale and change independently.
- Queues deliver to one consumer, topics with filtered subscriptions fan out to many, and features such as dead-letter queues, sessions, duplicate detection, transactions and scheduled delivery handle the hard edge cases.
- Choose Storage Queues for simple background jobs, [Event Hubs](https://www.m365.fm/entity/azure-event-hubs/?utm_source=podcast&utm_medium=shownotes&utm_campaign=azure-service-bus-simply-explained) and Kafka for high-throughput streaming, Event Grid for lightweight reactive events and Service Bus for reliable business workflows.

## FAQ

**What is the difference between a Service Bus queue and a topic?**

A queue delivers each message to one consumer, while a topic broadcasts a message to many subscriptions. Queues suit point-to-point work distribution. With topics, each subscription can filter on custom message properties, such as customer region or priority, so one customer registered message can reach the CRM, marketing and support systems separately.

**When should I use Azure Service Bus instead of Kafka or Event Hubs?**

Use Service Bus for commands and business workflows where you need to know a message was processed correctly. Event Hubs and Kafka are built for high-throughput event streaming and analytics, such as replaying last week's events. The episode notes they are complementary, and many large systems use Service Bus and Kafka together.

**What happens to messages that keep failing in Azure Service Bus?**

They are moved to the dead-letter queue instead of being silently lost. A message lands there when it exceeds its maximum delivery count or its time to live expires. The dead-letter queue is a sub-queue of the same queue or subscription, so you can inspect messages, fix malformed data or bugs and retry later.
