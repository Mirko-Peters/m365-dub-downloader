## Key takeaways

- Azure Front Door is a layer-7 global entry point that routes each user over Microsoft's backbone to the best healthy origin based on priority, latency and weight.
- The built-in web application firewall, bot protection and Private Link stop attacks at the edge and keep origin servers hidden from the public internet.
- Standard is the sweet spot for most websites and APIs, while Premium is worth it for regulated industries that need managed rule sets and Private Link.

## FAQ

**What is the difference between Azure Front Door and a load balancer?**

Azure Front Door works at layer seven, while most load balancers work at layer four. A layer-4 load balancer routes by IP address and port. Front Door understands HTTP and HTTPS, so it can inspect URLs, headers and content type and send API requests, images or other paths to different backends.

**How does Azure Front Door decide which origin gets a request?**

It first filters out unhealthy origins using health probes, then applies priority, latency and weight in that order. Lower priority numbers win, origins within the latency sensitivity window, 50 milliseconds by default, count as equally fast, and weights such as 90 and 10 split the remaining traffic for gradual rollouts or A/B tests.

**Should I choose Azure Front Door Standard or Premium?**

Standard suits most websites and APIs, while Premium fits regulated industries and sensitive data. At the time of recording Standard cost $35 and Premium $330 per month as base fees. Premium adds managed WAF rule sets, bot protection, Private Link and deeper security analytics; data transfer rates are identical across both tiers.
