## FAQ

**Why does RAG struggle when AI agents need to act?**

RAG struggles because it was built for static documents, not for work that changes by the minute. The episode explains that every retrieval cycle adds latency, separate vector indexes for SharePoint, email and Teams drift out of sync, and agents end up deciding on stale data. Work IQ instead reasons over live Microsoft 365 signals in place.

**Why are shared service accounts a problem for AI agents?**

Shared service accounts make agents ungovernable because nobody can tell which agent did what. The episode lists the gaps: no audit trail, no human owner, no lifecycle and no Conditional Access, and one compromised account exposes every agent behind it. Entra Agent ID gives each agent its own identity with scoped access, monitoring and revocation.

**How is Work IQ billed and how can organizations control the cost?**

Work IQ is billed by consumption in Copilot Credits rather than per user, according to the episode. Tool calls cost a fixed 0.1 credits, while chat and context costs vary with reasoning load. To control spend, the episode recommends batching retrievals, caching context, using lighter models for simple decisions and a FinOps practice with agent-level dashboards and alerts.
