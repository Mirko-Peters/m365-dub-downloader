## FAQ

**What is the difference between an AI agent and a chatbot?**

A chatbot is reactive and waits for your next question, while an AI agent is proactive and works toward a goal. The agent uses a large language model to reason about the request, breaks it into steps such as checking a calendar and sending an invite, then calls tools to act and uses memory to keep context.

**What is Microsoft Agent Framework and where does it come from?**

Microsoft Agent Framework is an open-source SDK that combines Semantic Kernel and AutoGen into one framework. It joins the enterprise stability of Semantic Kernel with the multi-agent patterns of AutoGen, treats Python and .NET as first-class languages, and works with several model providers, so switching providers means changing configuration rather than code.

**Should I use Copilot Studio or Microsoft Agent Framework to build an agent?**

Use Copilot Studio when you want to move fast without code, and Microsoft Agent Framework when developers need full control and deep customization. Copilot Studio offers a visual interface to connect data sources and publish to Teams. The framework is code-first with a VS Code extension, and its agents are deployed to Foundry for production.
