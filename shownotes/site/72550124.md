## FAQ

**How do you set up the Dataverse MCP server?**

You install a local proxy, give it your tenant ID and connection details, and point an MCP client at it. The episode describes downloading the Microsoft Power Platform Dataverse MCP tool, running it locally or in a container, and connecting a client such as Claude Desktop or GitHub Copilot, which then discovers the available operations.

**Is MCP slower than calling the Dataverse REST API directly?**

Yes, MCP adds latency, and the episode cites benchmarks of a 15 to 25 percent hit compared with direct REST calls. For bulk data movement, high-throughput jobs and latency-sensitive systems, REST stays the better choice. For AI agents, the episode argues MCP pays off through lower token usage, citing a range of 50 to 80 percent.

**Do DLP policies cover MCP servers in Power Platform?**

Not yet, according to the episode, because classic DLP policies recognize named connectors and MCP servers do not fit that taxonomy. Advanced connector policies are meant to close the gap, but they were in preview in early 2026 and only allow or block a whole server. Until then, restricted access lists and approval workflows act as interim controls.
