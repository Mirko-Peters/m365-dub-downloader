## FAQ

**Should a predictive maintenance project use Azure IoT Hub or Azure Event Hubs?**

It depends on which responsibility Azure takes on. IoT Hub fits when Azure must manage connecting devices, with device identities and device-to-cloud messaging. Event Hubs fits high-throughput ingestion from an approved plant application that already handles the equipment. Use both only when their separate duties justify the extra configuration, support work and failure paths.

**Do you need machine learning to start predictive maintenance on Azure?**

Not necessarily. The episode says to first measure existing practice, such as preventive maintenance, operator checks and condition-based maintenance, then test simple limit and trend rules with persistence requirements. A model has to earn a specific job by beating those rules on the same evaluation periods and the same definition of a useful warning.

**What should an edge gateway do when the connection to Azure drops?**

It should keep collecting measurements independently of uploads and store records on persistent local storage for later delivery. That needs a storage budget, a policy for a full queue, expiry rules and a log of any discarded records. After reconnecting, it drains the backlog at a controlled rate, and each reading keeps its event time.
