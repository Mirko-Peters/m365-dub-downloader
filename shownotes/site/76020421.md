## FAQ

**What is the Power Apps component framework (PCF)?**

PCF is Microsoft's framework for developers to build their own controls, called code components, for Power Apps. To app users they look and behave like any other control. A code component is a self-contained, reusable piece of interface that works in model-driven apps, canvas apps and Power Pages, and can be reused across environments.

**What is the difference between a canvas component and a code component?**

Canvas components are built inside an app with no code, while code components need real programming. Makers can reach for canvas components quickly. Code components are written in HTML, CSS and TypeScript with the Power Platform CLI, but offer far more capability and reuse across apps, including custom grids, maps and specialized input fields.

**When should I avoid building a PCF code component?**

Avoid it when a standard control or canvas component gets you most of the way there. A code component is custom software that needs a developer, an owner and ongoing maintenance across environments. If its only developer leaves, it becomes a black box, so build one only when the app truly depends on that control.
