## FAQ

**What does Microsoft Purview Data Loss Prevention protect against?**

Microsoft Purview DLP mainly protects against accidental leaks by your own employees, not hackers. It identifies sensitive data such as credit card numbers or health records, monitors it across email, SharePoint, OneDrive, Teams, devices and Copilot, and warns or blocks when someone tries something risky, like sending a file to a personal Gmail address.

**How does DLP work with Microsoft 365 Copilot?**

DLP for Copilot stops Copilot from generating responses that contain sensitive data. If a user asks for a summary of labeled confidential financials, Copilot can block the summary or leave out sensitive parts. The default Copilot DLP policies Microsoft deployed run in simulation mode, so they protect nothing until enforcement is turned on.

**How should you roll out DLP policies without breaking workflows?**

Start in audit or simulation mode, then move to policy tips, and only enforce once you are confident. The episode suggests a 90-day plan: audit from day one, analyze alerts by day 30, tune labels and exceptions by day 60, and enforce by day 90, aiming for a false positive rate under five percent.
