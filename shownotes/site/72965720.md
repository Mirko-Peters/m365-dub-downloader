## Key takeaways

- MCP is an open standard, originally created by Anthropic, that gives AI agents one common way to discover and call tools, resources and prompts instead of custom glue code per integration.
- Azure MCP Server is Microsoft's open-source MCP implementation that exposes Azure Storage, [Cosmos DB](https://www.m365.fm/entity/cosmos-db/?utm_source=podcast&utm_medium=shownotes&utm_campaign=azure-mcp-server-simply-explained), Azure Monitor, App Configuration and the Azure CLI to any MCP-compatible agent.

## FAQ

**What is Azure MCP Server?**

Azure MCP Server is Microsoft's open-source MCP server that sits between an AI assistant and your Azure environment. It is not a separate paid product or new Azure service. It wraps services such as Azure Storage, Cosmos DB, Azure Monitor, App Configuration and the Azure CLI behind one interface that any MCP-compatible agent can call.

**Does Azure MCP Server give AI agents extra permissions in Azure?**

No, it grants no new permissions. Authentication runs through Microsoft Entra ID and the Azure Identity library, and authorization follows Azure RBAC, so the agent can only do what your account is already allowed to do. With on-behalf-of authentication, downstream services see your identity, so every action appears in audit logs under your name.

**Which AI tools can connect to Azure MCP Server?**

Any client that speaks MCP can connect to it. The episode names GitHub Copilot agent mode, Semantic Kernel, Claude Desktop and custom agents you build yourself. It is also built into Visual Studio 2026. For remote use, Microsoft recommends the streamable HTTP transport, while STDIO suits local development on your own machine.
