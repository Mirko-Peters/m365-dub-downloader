## Key takeaways

- Copilot in Power Platform is four surfaces, not one: Power Apps, Power Automate and [Power BI](https://www.m365.fm/entity/power-bi/?utm_source=podcast&utm_medium=shownotes&utm_campaign=power-platform-copilot-integration) help you build, while Copilot Studio builds agents that answer on their own.
- Answer quality is capped by your data and instructions, so prepare semantic models and name Dataverse tables and columns clearly before relying on Copilot.
- Agent cost is a design decision: credits vary by answer type, internal agents for Microsoft 365 Copilot seat holders consume no credits, and exceeding prepaid capacity can disable agents.

## FAQ

**How much do Copilot Studio agents cost?**

Copilot Studio agents consume Copilot Credits pooled across the whole organization. At the time of recording, a scripted answer costs one credit, a generative answer two, an action five and grounding in your own data ten. A capacity pack is 200 dollars for 25,000 credits a month, while pay-as-you-go costs one cent per credit.

**What happens when Copilot Studio usage exceeds prepaid capacity?**

Custom agents get disabled once usage reaches 125 percent of prepaid capacity. A conversation already in progress finishes, but every later attempt is rejected and users see a billing or usage limit message. Setting a monthly consumption limit per agent keeps one enthusiastic team from draining the shared credit pool that other teams depend on.

**Why does Copilot in Power BI give generic or inaccurate answers?**

Usually because the semantic model was not prepared first, which Microsoft says can lead Copilot to misinterpret data. When a question does not relate to the model, Copilot answers from general knowledge in the same chat box. The same prompt against an unchanged model within 24 hours also returns a cached answer, so change the prompt or refresh.
