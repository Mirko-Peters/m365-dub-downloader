## FAQ

**Is Windows Subsystem for Linux free, and does it need an Azure subscription?**

Yes, WSL is free and needs no Azure subscription or Microsoft 365 plan. It ships as part of Windows 10 and Windows 11, including the Home edition. The link to Azure is a workflow: the Linux and Azure CLI commands you practice locally in WSL are the same ones used to deploy and manage real cloud systems.

**What is the difference between WSL 1 and WSL 2?**

WSL 1 translated Linux commands into something Windows understands, while WSL 2 runs a real Linux kernel inside a lightweight virtual machine that boots in seconds. That gives WSL 2 full system call compatibility, so tools like Docker work. Early WSL 2 was up to twenty times faster unpacking a tarball. WSL 2 is the default today.

**Why are file operations slow in WSL?**

File operations slow down when Linux tools work on files stored on the Windows side, or the reverse, because crossing that boundary is the slow path. Projects with thousands of tiny files suffer most. Microsoft advises keeping files in the same operating system as the tools, and the Remote WSL extension for Visual Studio Code helps with that.
