## FAQ

**What is the Model Context Protocol and how is it different from a REST API?**

MCP is a JSON-RPC 2.0 protocol that lets AI agents discover what a server can do instead of knowing an API surface in advance. After an initialization handshake, the server announces its tools, resources and prompts. Agents only need method names and typed schemas, not URL structures, HTTP verbs or status codes, which makes reasoning simpler.

**How do you connect an MCP server to Copilot Studio?**

You register the server endpoint, usually the Azure API Management gateway, configure authentication and set the protocol version. Copilot Studio then runs a discovery call and adds the tools to the agent. For production, use a Microsoft Entra service principal; API keys suit prototypes. If tools do not appear, check network path, token and initialization response.

**What are the most common mistakes when building MCP servers?**

The biggest mistake is putting business logic in the agent instead of the MCP server, where rules can be versioned, tested and reused. Others include running STDIO in production, hard-coding credentials, building one giant server for every tool, skipping observability and load testing, breaking backward compatibility, and deploying without a rollback plan.
