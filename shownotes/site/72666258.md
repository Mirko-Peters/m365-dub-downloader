## FAQ

**What does it mean to ground an agent in Dataverse?**

Grounding an agent in Dataverse means it reasons over your actual accounts, invoices, orders and interaction history instead of generic internet knowledge. Because Dataverse sits underneath Dynamics 365, the agent queries the same authoritative records your users see and inherits their security roles and row-level security, so it cannot see data it is not authorized to see.

**How does an account reconciliation agent speed up month-end close?**

An account reconciliation agent speeds up month-end close by matching invoices, purchase orders and general ledger entries automatically and identifying the root cause of each mismatch. It applies your tolerance rules, then drafts a journal entry for every exception. The entry is not posted until a controller approves it, which turns a manual investigation into a quick review.

**Why should data be cleaned before deploying Dynamics 365 agents?**

Data should be cleaned first because agents cannot work around duplicates and gaps the way people can. If one vendor appears under several names, an agent flags invoices that should match. The episode recommends merging duplicates, standardizing names, setting master data rules and aligning definitions, and estimates four to eight weeks of preparation before deploying at scale.
