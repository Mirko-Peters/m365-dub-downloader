## FAQ

**What does harvest now, decrypt later mean?**

It means attackers capture encrypted traffic today and store it until a quantum computer can break the key exchange that protected it. RSA and ECC still hold against classical computers, but data that must stay confidential for 10 to 20 years, such as health records or trade secrets, is already at risk once intercepted.

**What is cryptographic agility?**

Cryptographic agility is the ability to change algorithms without breaking systems. The episode describes four pillars: modular crypto libraries separate from application logic, API abstraction that hides algorithm choice, policy kept apart from code, and hybrid mechanisms such as X25519MLKEM768 that stay secure if either the classical or the post-quantum algorithm holds.

**What post-quantum cryptography does Microsoft already support?**

Several pieces are already available. The SymCrypt library supports ML-KEM and ML-DSA on Windows 11 and Windows Server 2025, Active Directory Certificate Services can issue ML-DSA certificates, and Edge enables hybrid post-quantum key exchange by default from version 147. Azure Key Vault also offers ML-KEM and ML-DSA key types in preview.
