## FAQ

**What is an AI agent harness?**

An agent harness is everything around the model that turns it into a working agent. The episode describes it as the agent loop, context management, tools and skills, memory and session persistence, guardrails, and orchestration of sub-agents. The model does the thinking, while the harness provides the workshop, checklist, supervisor and brakes.

**Why do AI agents fail on long multi-step tasks?**

They fail because a single prompt has no system around it to manage the work. On long tasks the context window fills up, the model forgets earlier instructions and starts inventing facts or delivering incomplete results. Better wording does not fix this; a harness that compresses context, remembers state and checks each step does.

**Which multi-agent patterns does the Microsoft Agent Framework support?**

The Microsoft Agent Framework ships five built-in coordination patterns: sequential, concurrent, handoff, group chat and Magentic. In the Magentic pattern from Microsoft Research, a supervisor agent creates a plan and delegates work to specialised sub-agents. The framework works in Python and C# and can use models from different providers, including local ones.
