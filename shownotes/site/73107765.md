## FAQ

**What is Microsoft Fabric in simple terms?**

Microsoft Fabric is a unified SaaS data and analytics platform that combines data engineering, data integration, data warehousing, real-time analytics and business intelligence. Instead of stitching separate products together, you get one experience and one login, with every workload storing its data in OneLake and no servers or networking for you to manage.

**What is the difference between a lakehouse and a warehouse in Microsoft Fabric?**

The difference is the interface, not the data. Warehouses are SQL first, built for people working with T-SQL, views and stored procedures. Lakehouses are developer first, built for Spark, Python and notebooks, and can also hold raw files. Both store data in OneLake, so data loaded into one is immediately queryable from the other.

**What is Direct Lake mode in Power BI?**

Direct Lake lets Power BI query data where it sits in OneLake instead of copying it into Power BI's internal storage, as import mode does. According to the episode, this means no refresh, no duplication and data that is always current, while the semantic model underneath still defines business logic, measures and relationships.
