## FAQ

**What is Microsoft Agent 365?**

Microsoft Agent 365 is a control plane that gives an organization one place to see, govern and secure every AI agent it runs. Rather than a new system to learn, it sits on existing tools: Microsoft Entra for identity, Microsoft Defender for security, Microsoft Purview for data and the Microsoft 365 admin center as the front door.

**What does the Agent Registry in Agent 365 show?**

The Agent Registry is a single list of every agent in the company, from Microsoft and partner agents to those published by your organization or individual creators. It tracks total agents, agents without owners and unmanaged agents, and admins can quarantine or block an agent nobody sanctioned without breaking the surrounding work.

**How is Microsoft Agent 365 licensed and priced?**

Microsoft Agent 365 is licensed per person, not per agent, so one license covers every agent an employee uses or sponsors. At the time of recording it cost fifteen dollars per user per month on an annual plan, and it is also included in Microsoft 365 E7, listed at ninety-nine dollars per user per month.
