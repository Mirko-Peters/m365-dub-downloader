## FAQ

**Does Microsoft 365 Copilot respect SharePoint permissions?**

Yes, Copilot uses security trimming through Microsoft Graph, so it only shows content the user can already open. The problem is that most tenants carry years of over-permissioning, such as organization-wide sites, stale group memberships and unrevoked sharing links, and the semantic index makes all of that discoverable simply by asking a question.

**Can sensitivity labels stop Copilot from summarizing a document?**

Yes. Copilot needs both view and extract rights to summarize encrypted content, so removing extract rights from a label blocks summaries while people can still read the file. The block content analysis services setting, configured through PowerShell, goes further, and Double Key Encryption keeps document content completely out of reach of Copilot.

**How do you stop a Copilot prompt injection attack in progress?**

You revoke the user's Entra ID sessions, because there is no dedicated Copilot session kill API. A Sentinel automation rule can trigger a playbook that calls Microsoft Graph to revoke sign-in sessions, which ends all Microsoft 365 sessions for that user, documents the action on the incident and notifies the SOC team.
