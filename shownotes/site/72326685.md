## FAQ

**What is LoRA fine-tuning?**

LoRA, or low-rank adaptation, freezes a base model and trains small matrices inserted into selected layers instead of updating every weight. With a rank of 16 on a 4,000 by 4,000 layer, it trains under 1% of the parameters, and the result is an adapter file of a few megabytes rather than a full model copy.

**Can you fine-tune an LLM on a single GPU?**

Yes, by combining LoRA with 4-bit quantization. Storing the frozen base weights in the NF4 format cuts memory by roughly 75%, so a Mistral 7 billion parameter model with LoRA adapters can be fine-tuned on one GPU with 16 gigabytes of VRAM, using standard, well-documented open source libraries rather than GPU clusters.

**Why isn't Microsoft 365 Copilot enough to stop shadow AI?**

Copilot's protections cover only the Microsoft layer. Prompts stay isolated by tenant and are not used to train foundation models, but employees who paste internal documents, stack traces or forecasts into public chatbots on personal accounts bypass those controls. The episode calls this space between approved tools and actual behavior the sovereignty gap.
