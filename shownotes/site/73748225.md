## FAQ

**What is agentic RAG and how is it different from traditional RAG?**

Agentic RAG turns the language model from a passive summarizer into a decision maker that plans what it needs, retrieves from several sources and evaluates the results. Traditional RAG runs one pass from query to vector database to answer. The agentic version follows the ReAct pattern, reasoning and acting in a loop until it has enough to answer.

**When should you use traditional RAG instead of agentic RAG?**

Use traditional RAG for simple factoid questions with one obvious source, such as a PTO policy or a guest Wi-Fi password. Running these through an agentic loop adds planning, evaluation and extra model calls for the same answer. The episode cites agentic RAG at two to ten times the cost and noticeably slower, so volume matters.

**How should organizations govern Copilot agents that act on their own?**

Govern each agent like an employee: give it its own identity in Microsoft Entra with defined access controls and an audit trail of what it did. Microsoft Purview then applies compliance oversight and data loss prevention policies to agent actions just as it does for people. Grounding and safety checks must also be enforced more strictly as autonomy grows.
