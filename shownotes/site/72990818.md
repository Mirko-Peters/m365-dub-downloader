## FAQ

**What does Azure Resource Manager actually do?**

Azure Resource Manager is the central control plane that every create, update or delete request in Azure passes through. Whether you use the portal, the command line, PowerShell or an SDK, ARM validates the request, checks your permissions and coordinates the compute, storage and network services, so every tool produces the same result.

**How should I organize Azure resource groups?**

Group resources by application and lifecycle, not by type. Every resource belongs to exactly one resource group, and resources in a group share permissions, policies and lifecycle, so deleting the group removes everything inside it. Keeping a web app, its database and storage together makes access, cost tracking and cleanup much simpler.

**What happens if an ARM template deployment fails partway through?**

ARM rolls back the entire deployment and deletes the resources it already created, so you return to a clean state. In the episode's example, if the database creation times out, nothing is left half deployed. You fix the issue and run the same template again, which works because templates are declarative and idempotent.
