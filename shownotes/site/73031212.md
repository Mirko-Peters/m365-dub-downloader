## Key takeaways

- Every Azure customer gets free infrastructure-level DDoS protection, but it protects Azure's platform and may not mitigate moderate attacks against your specific workload.
- Azure DDoS Protection comes as Network Protection, with rapid response support, cost protection and a WAF discount, or as the cheaper per-IP IP Protection, both adding adaptive tuning, metrics and logging.
- Because DDoS protection only covers layers 3 and 4, a Web Application Firewall with the HTTP DDoS rule set, rate limiting and bot protection is needed to stop layer 7 attacks.

## FAQ

**Does Azure protect my app from DDoS attacks for free?**

Only partly. Every Azure customer gets always-on infrastructure-level DDoS protection at no cost, but it is designed to protect Azure's platform. Its thresholds are high, it gives no alerts or reports, and a moderate attack against your specific application may not trigger mitigation, even though it can still take your server down.

**What is the difference between Azure DDoS Network Protection and IP Protection?**

Network Protection covers every public IP in a virtual network and adds rapid response support, cost protection and a WAF discount. IP Protection is priced per public IP and is cheaper for small setups, but drops those extras. Both provide the same core layer 3 and 4 mitigation, adaptive tuning, metrics and logging.

**Does Azure DDoS Protection stop layer 7 attacks?**

No, Azure DDoS Protection only covers layers 3 and 4 and never inspects HTTP request content. For layer 7 attacks you need a Web Application Firewall on Application Gateway or Azure Front Door, using the HTTP DDoS rule set, rate limiting and bot protection. The episode sums it up as DDoS protection handling the flood and WAF the fakes.
