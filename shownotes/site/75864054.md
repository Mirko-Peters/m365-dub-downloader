## FAQ

**Do you need to replace ERP or MES to connect them with IoT data?**

No. ERP keeps the business commitment, MES keeps the execution record and the PLC and IoT layer keep the physical signal. Integration connects their meaning through asset identity maps, shared state models, named owners and versioned data contracts. A data platform reads broadly and writes narrowly, routing changes back through approved workflows.

**What is a unified namespace in manufacturing?**

A unified namespace is a governed shared event space where machine data and MES events are published once and approved consumers subscribe. An MQTT broker usually distributes the messages. It reduces point-to-point connections, but it does not replace ERP transactions, historical storage or request-response APIs, and it still needs governed names, states and owners.

**Should a factory standardize on OPC UA, MQTT or REST?**

No single protocol fits everywhere, so choose by source and decision. OPC UA suits newer machines exposing structured data, digital I/O suits older equipment, MQTT distributes current events to several consumers, and REST APIs handle ERP and MES objects and transactions. A protocol moves data but does not define what it means.
