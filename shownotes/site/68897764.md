## FAQ

**Why do customer journeys fail without showing any errors?**

Most journeys die silently because no trigger evaluation ever happens. In the abandoned cart case, the cart value threshold was empty and the consent lattice was never called, so no message was created. Delivery dashboards stayed green because they only measure sends, so teams need monitors that alert when eligible events produce zero evaluations.

**What is a consent lattice in Customer Insights journeys?**

A consent lattice resolves permission across person, brand, purpose, region and sometimes channel and jurisdiction, returning allowed, denied or conditional with the precedence path. In the episode, a profile said email was allowed while a brand-level block denied it. Journeys should call one resolver before the first channel tile and branch to a lawful fallback.

**How do you prevent trigger loops in real-time journeys and Power Automate?**

Shield triggers from self-writes with a predicate that ignores updates made by the journey service principal, then add debounce windows keyed on a case hash. Stamp idempotency keys so duplicates return already processed, back off five, 15 and 45 minutes on throttling, and install loop breakers that pause the journey and page on call.
