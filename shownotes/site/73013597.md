## FAQ

**What is the difference between SIEM and SOAR in Microsoft Sentinel?**

SIEM collects and correlates logs to spot attacks, while SOAR responds to them automatically. Sentinel does both: it links a suspicious Entra sign-in with SharePoint downloads and Exchange forwarding rules, then runs playbooks built in a visual designer that can disable accounts, block devices, revoke sessions and notify the security team.

**How does the Microsoft Sentinel data lake reduce log storage costs?**

The data lake separates storage from compute, so data sits in a low cost tier and you pay for compute only when you query it. Microsoft says this costs less than 15% of traditional analytics logs. Retention can reach 12 years, and ingested logs are mirrored into the lake automatically.

**Will Microsoft Sentinel still be available in the Azure portal?**

No, Sentinel is moving into the Microsoft Defender portal. According to the episode, after March 30, 2027 it will no longer be available in the Azure portal. Admins then see incidents, hunt for threats and manage security posture in one place instead of switching between the Azure portal and the Defender portal.
