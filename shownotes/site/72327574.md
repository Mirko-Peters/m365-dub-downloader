## FAQ

**Should I use Logic Apps Standard or Consumption to orchestrate AI agents?**

Use Logic Apps Standard for enterprise agent orchestration. It runs on single-tenant infrastructure with virtual network integration, custom connectors, stateful and stateless workflows side by side, deep DevOps integration and the agent loop action. Consumption bills per action and suits personal or departmental automations, but offers less control over compute and lifecycle management at scale.

**How can a Logic App call APIs in another tenant without a client secret?**

Use workload identity federation instead of a secret. The Logic App's managed identity obtains a token from its own platform, and a federated identity credential on an app registration in the target tenant trusts that issuer. The target tenant validates the token and issues an access token limited to the permissions granted by admin consent.

**When should a Logic Apps workflow be stateful instead of stateless?**

Use stateful whenever a process waits for approvals, callbacks or retries, or must survive restarts. Stateless workflows run in memory, are faster and scale better, but stop after five minutes and keep no checkpoints or detailed run history. The recommended design runs stateless workflows for quick lookups and stateful ones for long, cross-tenant processes.
