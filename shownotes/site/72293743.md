## FAQ

**Why combine Microsoft Graph API with the n8n SharePoint module?**

Each one returns data the other lacks. The n8n SharePoint module does not provide the internal file ID needed for dynamic downloads, while Graph API does but is less reliable for last-modified timestamps. Two parallel paths read the same folder, and a merge node joins them by file name into one complete record per file.

**How does the RAG agent answer numerical questions from spreadsheets?**

It uses a SQL tool instead of vector search. Excel and CSV files skip chunking and embedding, and each row is stored as JSON in a Postgres table. When a question needs calculation, such as total revenue across monthly rows, the agent writes a SQL query, because language models are unreliable at arithmetic.

**How does this private RAG design stay GDPR compliant?**

It keeps processing inside the EU by design. Embeddings run on Azure OpenAI with a data zone standard deployment in an EU region, the stack is self-hosted on a German server, and re-ranking goes to Cohere under Canada's adequacy decision. Deleted SharePoint files are removed from vectors and metadata automatically to support erasure requests.
