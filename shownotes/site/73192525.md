## FAQ

**What is the difference between Azure Virtual Desktop and Windows 365?**

Azure Virtual Desktop is a platform-as-a-service offering, while Windows 365 is software as a service. With AVD you keep all the VDI controls and can save money with autoscaling, but you manage it yourself. Windows 365 handles scalability, images and the backend for you, so anyone with Microsoft 365 and Intune knowledge can run Cloud PCs.

**Will AI agents replace endpoint administrators?**

Not in the near term, according to Christiaan Brinkhoff. He expects admins to gain digital helpers: task-specific agents, for example for security or policy management, with tightly scoped permissions that admins stay in control of. Over the next two to five years, knowing the systems remains important, and building the agents and automation becomes a key skill.

**Will MCP replace the Microsoft Graph API for managing Intune?**

No, Christiaan sees MCP building on top of Graph rather than replacing it. An MCP server could connect to the Intune backend through Graph, so Graph has more future than graphical consoles. How quickly this becomes the standard depends on IT pros changing habits, and many customers still use the classic UI without touching Graph.
