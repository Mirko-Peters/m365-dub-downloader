## FAQ

**How is Microsoft Purview changing data security in the age of AI?**

Microsoft Purview is shifting data security from blocking users to monitoring their behavior. Danilo compares the old approach of proxy servers and blocked sites with today's monitoring of activity, such as large SharePoint downloads or departing employees, and describes Insider Risk Management with Adaptive Protection taking automatic actions when risky behavior appears.

**What should organizations fix before rolling out Microsoft 365 Copilot?**

Organizations should fix permissions and oversharing first, because Copilot can surface any document a user already has access to. Danilo gives the example of a user asking about salaries in the company. He recommends mapping SharePoint sharing, using access governance tools and establishing data governance: knowing where data lives, where it goes and who sees it.

**How will agents help security analysts in Microsoft Purview?**

Agents in Microsoft Purview are meant to triage alerts so analysts know which ones need attention first. Danilo explains that out of a large number of alerts, agents point to the most important ones based on the environment and the instructions given, and show a user's activity history over recent days to support the investigation.
