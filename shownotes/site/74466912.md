## FAQ

**What is AL in Business Central?**

AL, short for application language, is Microsoft's programming language for Business Central. Developers use it to add data, screens, reports and business rules or to change how existing parts behave. It is focused on shaping data and behavior inside Business Central, so it is not meant for public websites, mobile games or standalone desktop apps.

**Why are Business Central extensions safer than editing the base code?**

Extensions keep custom work in a separate app beside the standard application, connected through supported points such as events. In older C/AL systems, developers often edited original objects directly, so every update meant reconciling changes. With extensions Microsoft updates its part while custom code stays separate, although teams still test their extensions after updates.

**What do I need to start AL development for Business Central?**

You need Visual Studio Code with Microsoft's AL language extension, which suggests object names, flags errors and connects your project to a Business Central environment. Test in a sandbox so mistakes never affect live records, use breakpoints to debug, and keep the project in Git. Start small with one table, one page and one simple rule.
