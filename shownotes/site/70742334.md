## FAQ

**Why do quarterly access reviews fail in Microsoft 365?**

They fail because many owners never respond, and admins approve by default to avoid blocking the business. The episode cites 40 percent non-response, which turns reviews into documentation of absent objections. Mirko argues access should instead expire by default, with extensions requiring a justification that is checked again against current context.

**What does Agent 365 do for AI agent governance?**

Agent 365 acts as the control plane for AI agents. Each agent receives a Microsoft Entra Agent ID with an owner, a defined purpose and scoped permissions. Agents that violate policy are blocked automatically, and inactive agents are flagged for review and later deleted, so agents follow a lifecycle like user identities.

**What should Microsoft 365 admins do first to move away from manual administration?**

Start with four actions: enable Privileged Identity Management for key roles with a maximum activation of eight hours, justification and MFA; block external sharing by default; inventory every agent with owners and lifecycle rules; and rewrite policies as intended states, such as inactive accounts expiring automatically, instead of task steps.
