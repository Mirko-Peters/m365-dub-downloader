## Key takeaways

- A value stream map is a snapshot that decays quickly, but it can become a live model when it is regenerated from ERP, MES, quality, maintenance and shop floor events.

## FAQ

**Can a value stream map be updated automatically from factory data?**

Yes, partly. A live model can regenerate its view of flow from ERP, MES, quality, maintenance and shop floor events, but only after the team agrees what each state means. Workshops still matter, because people define the flow, test what the model claims and correct it when the factory proves it wrong.

**Does a live value stream map need data that refreshes every second?**

No. A live model should refresh at the pace of the decision it supports. A shift supervisor may need updates during the shift, a planner several times a day, and improvement teams weekly or monthly history. Each view should declare its freshness, its source and whether parts of the sequence were inferred.

**What role does Microsoft Fabric play in a live value stream model?**

Fabric provides the data foundation, not the process truth. It can keep raw records from ERP, MES, quality and machine sources alongside curated tables with approved mappings and event rules, and support semantic models for Power BI. It will not invent a shared order identifier or decide who owns a stalled handoff.
