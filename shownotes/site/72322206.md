## FAQ

**Why can't robot control loops run in a cloud region?**

Because physics sets a hard latency floor that no bandwidth upgrade removes. Light in fiber adds about five microseconds per kilometer, and real round trips to a cloud region often reach 30 to 80 milliseconds with unpredictable jitter. A robot that needs updates every one to ten milliseconds becomes unstable, so the control logic has to run locally.

**What is the difference between Private 5G and Wi-Fi in a factory?**

Private 5G uses scheduled access with guaranteed quality of service, while Wi-Fi is contention-based and best effort. A 5G base station allocates resources per device and per slice, so a burst of video cannot delay a safety command. The episode recommends a converged fabric: Wi-Fi 7 for offices and collaboration, Private 5G for operational technology.

**Does Azure Private 5G Core keep working if the WAN connection drops?**

Yes, the local network keeps running because only the management plane lives in Azure. Azure Private 5G Core runs on Azure Stack Edge on premises, so user plane traffic stays in the facility. During an outage robots, cameras and inference containers keep working; you only lose remote configuration changes and dashboards until the link recovers.
