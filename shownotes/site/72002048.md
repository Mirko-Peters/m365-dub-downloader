## FAQ

**Is WPF still worth using for new desktop applications?**

Yes, if the app only needs to run on Windows, according to Gabor Ruzsinszki. WPF is still supported in modern .NET, deploys easily, has excellent Visual Studio tooling and a large pool of existing controls. For macOS or other platforms he points to .NET MAUI, which shares the XAML philosophy, so WPF knowledge transfers well.

**When should you choose gRPC instead of REST in .NET?**

Choose gRPC for fast backend-to-backend communication, especially across services written in different languages. It uses a binary format and Protocol Buffers definitions, from which code is generated for each language. REST remains the natural fit for browser front ends because browsers speak JSON natively, and Gabor does not expect gRPC to replace it.

**Are minimal APIs in ASP.NET Core better than controllers?**

It depends on the size of the service. Gabor finds minimal APIs ideal for small services with three or four endpoints, where controllers feel like overkill, and compares them to Python's Flask. For large applications with hundreds of endpoints he would stick with controllers, since teams tend to reinvent that structure anyway.
