## FAQ

**Why do users skip metadata dropdowns in SharePoint?**

Because tagging costs them time and gives them no personal benefit, so skipping becomes the default. Long dropdowns hide options and break flow, and decision fatigue means tagging quality drops through the day. Training cannot change that cognitive cost, which is why the episode treats dropdowns as a design failure rather than a user problem.

**How can Microsoft Graph tag SharePoint files automatically?**

An event-driven Azure Function, triggered by a webhook when a file is uploaded, queries Microsoft Graph for context and writes the metadata back. It reads the uploader's department, the team's project and the site's properties, applies classification rules, stores results as schema extension properties and applies a Purview sensitivity label, usually within seconds.

**Should governance metadata use open extensions or schema extensions in Microsoft Graph?**

Schema extensions are the better fit because they are typed, registered in the tenant and discoverable by other applications. Open extensions let any app add custom data but lack strong typing and discoverability. Registering a schema needs administrator consent and versions the structure, so search, compliance reports and AI pipelines can rely on it.
