## FAQ

**Why can't AI optimize production with only ERP, MES and machine data?**

Because each system holds only part of the story, and AI cannot judge consequences without context. It needs to know which product ran on the stopped machine, which order depends on it, what could run elsewhere and which production rules apply. Without those connections it can summarize alarms but not recommend a safe response.

**What is the difference between a knowledge graph and a digital twin in manufacturing?**

A knowledge graph describes relationships, while a digital twin puts a model of something real to work for a specific operational job. The episode distinguishes asset, line and order twins by decision. If something only reports status, call it a dashboard; if it organises signals, call it a tag model.

**Should generative AI or a copilot make production decisions?**

No, generative AI should explain, not decide. A large language model can understand a planner's question, retrieve approved facts, explain why a route failed and compare scenarios. Optimization searches for feasible plans, deterministic checks verify conditions, and a named person approves. AI must never bypass safety systems or write directly to a PLC.
