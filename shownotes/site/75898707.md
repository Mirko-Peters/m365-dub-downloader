## FAQ

**What is the difference between the DTU and vCore models in Azure SQL Database?**

The DTU model bundles compute, storage and I/O into one number, while the vCore model lets you choose compute and storage separately. DTU offers Basic, Standard and Premium tiers with a predictable price. vCore, which Microsoft recommends, adds Azure Hybrid Benefit, serverless and Hyperscale. You can convert a database between both models online.

**How long does Azure SQL Database keep automatic backups?**

Point-in-time restore covers seven days by default and can be configured up to thirty-five days. Azure takes weekly full, differential and roughly ten-minute log backups automatically. For longer history, you must turn on long-term retention, which keeps full backups for up to ten years. The automatic backups cannot be downloaded; you export a portable package instead.

**When should I use SQL Server on an Azure virtual machine instead of Azure SQL Database?**

Choose a virtual machine when you need operating system access, full engine control, an exact match of an on-premises setup, or a lift with no code changes. You then own patching, backups and failover. For most migrations Microsoft recommends Azure SQL Managed Instance, and beginners should start managed unless they have a specific reason.
