## FAQ

**Do I still need a local STDIO proxy to connect Claude to Dataverse?**

No, clients like Claude Desktop, Claude Code and GitHub Copilot now support remote HTTP endpoints, so they can call the Dataverse MCP server directly. One long-lived endpoint pools connections, authenticates once and logs centrally, while separate proxies per user multiply processes, authentication sessions and scattered logs that make governance and auditing very hard at scale.

**How do I register an Entra ID app for the Dataverse MCP server?**

Create an app registration in Entra ID, add the MCP permission and copy the application ID. Then add that ID to the environment allow list in the Power Platform admin center, enable public client flows so PKCE works, and register the redirect URIs for Claude Desktop, Claude Code and GitHub Copilot. No client secret is needed.

**Can an AI agent delete Dataverse records through MCP without approval?**

No, the delete record tool carries a requires confirmation flag, so clients like Claude or GitHub Copilot must show the user a confirmation dialog first. Every tool call, including whether the confirmation was approved or denied, is written to the Dataverse audit trail, and the user's existing roles and row and field level security still apply.
