## FAQ

**Can I run production apps in the default Power Platform environment?**

No, the default environment is meant for experiments and small personal tools, not for apps your business depends on. It is shared with the whole company, cannot be deleted, has no backup guarantees from Microsoft and a one terabyte ceiling. Build in a developer or sandbox environment and ship to a production environment instead.

**Why can't my Power Apps app see data from another environment?**

An app can only connect to data sources that live in the same environment, so data in another environment stays invisible no matter how correct the logic looks. Each environment keeps its own Dataverse database and data does not flow between them. A broken connection is often this boundary doing its job rather than a bug.

**Why does a Power Platform app show empty screens even though I am an environment maker?**

The Environment Maker role lets you create apps, connections and flows, but it grants no rights to the data itself. You also need a Dataverse security role such as Basic User, or System Customizer if you update tables. That mismatch is the most common cause of the works-for-my-colleague-but-not-for-me confusion.
