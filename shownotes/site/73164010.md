## FAQ

**What is an agent skill and why does it make AI agents faster and cheaper?**

An agent skill is a self-contained package of instructions, metadata and bundled resources that loads only when a request needs it. Through progressive disclosure the agent keeps just skill names and descriptions in context, so each turn processes fewer tokens, which lowers latency and Copilot Credits consumption compared with one monolithic system prompt.

**Should guidance go into agent instructions or into a skill?**

Ask whether the rule is true in every conversation. If it is, such as tone, role identity or universal guardrails like protecting personal data, it belongs in the instructions. Situational guidance, such as a vendor refund procedure or blackout-period leave rules, belongs in a separate skill that loads only when relevant.

**Are agent skills from public registries a security risk?**

Yes, because skills can bundle executable scripts. The episode cites an analysis of nearly 100,000 public skills that found 157 confirmed malicious ones. It recommends zoned environments with DLP policies, static analysis, sandbox execution, least-privilege service accounts, runtime logging and quarterly recertification before skills reach production.
