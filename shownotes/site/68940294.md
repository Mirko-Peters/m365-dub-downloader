This episode is for Windows and identity administrators and security teams who want to understand how attackers follow that drift through Kerberos, NTLM and delegation, and which baselines, tiering and detection practices keep AD in a stable orbit.

## Key takeaways

- Active Directory rarely fails in one misstep; security drift accumulates through forgotten trusts, temporary GPOs, overprivileged service accounts and unpatched legacy hosts.
- Kerberos delegation, stale KRBTGT secrets, NTLM relays and shared local admin passwords are the slopes attackers follow, countered by constrained delegation, KRBTGT rotation twice, SMB signing, LDAP channel binding, LAPS and gMSA.
- Tiered administration with PAWs, Credential Guard and LSA protection, Sysmon and security log correlation, rehearsed forest recovery and named owners keep the directory stable and make drift visible.

## FAQ

**How should you reset the KRBTGT password in Active Directory?**

Reset it twice, spaced by the maximum ticket lifetime, with replication health checked between passes. The episode treats this as a planned cadence and something to repeat after any compromise, because forged tickets built from an old KRBTGT secret can otherwise still be honored. A stale password last set long ago is flagged as overdue.

**Why is unconstrained delegation dangerous and what should replace it?**

Unconstrained delegation lets a server request tickets to anything on behalf of visiting users, so privileged TGTs can sit in its memory for an attacker to reuse. The episode recommends removing it, using constrained delegation scoped to exact SPNs, preferring resource-based constrained delegation, and denying interactive logon to service accounts.

**How do you protect Active Directory against NTLM relay attacks?**

Disable LM and NTLMv1 outright, require SMB signing on clients and servers, and enforce LDAP channel binding so captured responses cannot be replayed elsewhere. Turn on NTLM auditing to find where it still flows, allow-list the few services that need it, put critical admins in Protected Users and stop the print spooler where unneeded.
