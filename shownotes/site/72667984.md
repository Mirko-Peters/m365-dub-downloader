## FAQ

**Does Terraform store secrets in the state file?**

Yes, Terraform's state file stores resource configuration, including values such as database passwords, connection strings and keys, in plaintext JSON. Marking a value as sensitive only hides it from console output. That makes the state backend a high-value target, so according to the episode access control matters as much as encryption at rest.

**Does Bicep need a state file like Terraform?**

No, Bicep has no state file because Azure Resource Manager acts as the source of truth. You send a desired state, and ARM compares it with what actually exists and changes only what differs. There is no backend to secure or lock, and the what-if operation previews changes against live data instead of a stored state file.

**When should an organization choose Terraform or OpenTofu over Bicep?**

Terraform or OpenTofu makes sense when you run significant workloads on more than one cloud and need a single tool and language across them. Organizations that avoid business source licensed software can pick OpenTofu, which the Linux Foundation governs under MPL 2.0. Azure-only organizations usually gain more from Bicep's simplicity and native governance.
