## Key takeaways

## FAQ

**What is Azure Files?**

Azure Files is a fully managed cloud file share that you mount like a network drive. Microsoft handles the hardware, updates, backups and availability. Windows connects over SMB, Linux over NFS, and Macs are supported too. Users simply see a drive letter or folder path, whether the share is reached over the internet or a private network.

**What changes with the new standalone file shares resource in Azure?**

The new file shares resource removes the storage account parent, so each share becomes its own top-level resource. Every share gets its own IOPS, throughput and capacity limits, its own network rules and its own billing line. There is no all-powerful storage account key. At general availability it supports only the SSD tier and NFS.

**When should you not use Azure Files?**

Avoid Azure Files for high performance databases, where Azure SQL or managed disks fit better, and for real-time document collaboration that SharePoint and Teams already handle. It is also a poor match for applications needing symbolic links, hard links or extended attributes. Check your requirements before committing, since it covers standard file system behavior, not every edge case.
