## Key takeaways

- Azure Backup is a managed platform that protects Azure VMs, SQL Server and SAP HANA databases, file shares, blobs, disks and on-premises servers from one vault, driven by policies.
- Encryption, soft delete, immutability, multi-user authorization and Defender for Cloud malware scanning make backups hard for ransomware attackers to destroy or poison.
- A backup is only proven once it has been restored, so schedule regular restore drills and review retention policies to avoid paying for recovery points you never need.

## FAQ

**What workloads can Azure Backup protect?**

Azure Backup protects Azure VMs, SQL Server and SAP HANA databases running in Azure VMs, Azure file shares, blobs and individual disks. It also covers on-premises physical servers and VMware virtual machines through Microsoft Azure Backup Server or the MARS agent, so a single vault and one set of policies can manage everything.

**How does Azure Backup protect backups against ransomware?**

It layers several defenses so attackers cannot simply delete or poison backups. Data is encrypted with AES 256 at rest, soft delete keeps deleted backups for 14 days, immutability locks recovery points until retention expires, multi-user authorization requires two people for critical changes, and Defender for Cloud scans restore points for malware.

**How much does Azure Backup cost?**

Pricing has two parts: an instance fee per protected resource plus vault storage. In the episode, a 200 GB VM with LRS storage runs roughly $15 to $20 per month at the time of recording. GRS costs about twice as much as LRS, while the archive tier, selective disk backup and reserved capacity lower costs.
