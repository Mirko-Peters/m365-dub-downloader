- Unified routing first classifies incoming work with skills, language and priority, then assigns it to an available agent who has the right skills and free capacity.

## FAQ

**What is unified routing in Dynamics 365?**

Unified routing is one routing approach that sends chats, calls, messages and case records to the best suited agent. It first classifies incoming work, adding skills, language and priority, then assigns it to an available agent who has matching skills and free capacity, applying the rules service leaders defined the same way every time.

**What is the difference between push and pick assignment?**

With push assignment, Dynamics 365 sends a new item directly to an eligible agent, which suits busy service desks that need speed and steady distribution. With pick assignment, qualified agents see waiting work in a queue and choose what to take, which suits senior teams handling complex cases that need a quick review first.

**In what order should you set up unified routing?**

Start by writing down your service policy in plain language, then create queues, add the people, define their real skills and set capacity profiles. Only after that build workstreams and routing rules. Otherwise rules can point to teams, skills or capacity settings that do not exist yet, which makes testing and troubleshooting harder.
