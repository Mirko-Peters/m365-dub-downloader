## FAQ

**Should a Power Platform project start by building an app?**

Usually not. Start by naming the dominant constraint in the process, not the tool. For the Contoso leave process the suggested order is: define the data, design and automate the approval path, build the app around key interactions, add reporting, and only then add an assistant layer if conversational access actually helps.

**What is the difference between canvas apps and model-driven apps?**

Canvas apps center on the experience: you shape the interface freely around a specific task, which suits simple, mobile-friendly interactions like submitting a request. Model-driven apps center on the data and are stronger when a process depends on complex relationships, large record sets and tight control, such as an HR workspace managing many records.

**When should you use Dataverse instead of SharePoint or SQL?**

Dataverse fits when a process behaves like an application capability: records need consistent relationships, several tools must share one structure, and security, reusable logic and lifecycle control matter. SharePoint suits lighter, collaboration-oriented scenarios, while SQL offers deep control for high-volume or specialized workloads. Not every build needs Dataverse from day one.
