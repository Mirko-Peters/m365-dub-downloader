## FAQ

**What is Microsoft Cloud PKI?**

Microsoft Cloud PKI is Microsoft's managed certificate authority service inside Intune. It issues, renews and revokes certificates for devices that Intune manages, without on-premises servers. Microsoft can host both the root CA and the issuing CA, and in licensed production use protects the CA keys with hardware security modules, so you do not run that hardware yourself.

**Which devices and scenarios does Cloud PKI support?**

Cloud PKI covers Intune-enrolled Windows laptops, Macs, iPhones, iPads and Android devices, typically for certificate-based Wi-Fi, VPN and internal app access. It is not a general replacement for certificates on web servers, VPN gateways or load balancers, and it does not cover unmanaged computers, isolated systems or Linux devices outside Intune support.

**How does a device get a certificate from Cloud PKI?**

Intune first sends the trusted root and issuing certificates to the managed device. The device then creates its own private key locally and sends a certificate request through SCEP. Intune confirms the device is enrolled and protects the request, the issuing CA signs the certificate, and Intune delivers it back without the private key ever leaving the device.
