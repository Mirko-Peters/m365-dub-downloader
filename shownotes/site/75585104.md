## FAQ

**Why doesn't a priority flag in ERP make an urgent order feasible?**

Because a flag does not create capacity. The plant still has the same machines, people, material and hours, so the urgent order takes machine time, inspection slots or labor from confirmed orders. The real question is which commitments move, and that needs scheduling logic that traces the impact through the actual route.

**Can OEE tell you whether to accept an urgent order?**

No, OEE answers an equipment question, not an order question. It measures availability, performance and quality of an asset, but a machine can look healthy while the urgent order waits on inspection or another resource. OEE data is still useful for setting honest capacity assumptions in the schedule.

**What is a shared promise process in manufacturing?**

It is a defined path for committing delivery dates before the customer receives one. Sales enters the product, revision, quantity, date and conditions, the request gets an urgency category with a clear reason, and planning tests feasibility. Each group has a defined part, instead of passing the request over the wall.
