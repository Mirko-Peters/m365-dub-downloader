## FAQ

**Why is a production schedule outdated before the first order starts?**

Because a released ERP schedule is a decision built on yesterday's facts. Between release and execution, material is not at the line, a tool is not ready, a qualified person is off shift or a machine has short stops. ERP does not see those execution conditions, so the plan keeps treating its assumptions as current reality.

**Why do production planners keep using Excel instead of the planning system?**

Excel survives because it solves an immediate problem faster than the formal process. A planner can change a sequence in seconds, add notes and send a revised file. It also holds knowledge the formal model never captured, such as setup families or who can run what. The episode recommends absorbing that knowledge rather than banning spreadsheets.

**What role does Microsoft Fabric play in closed-loop production scheduling?**

Microsoft Fabric is the shared data foundation, not the factory brain. It brings ERP, MES, quality, maintenance and IoT data into governed data products with common identifiers, lineage and shared definitions. It does not infer capability rules, sequence restrictions or tool requirements, so those relationships still need explicit modeling before replanning can produce feasible schedules.
