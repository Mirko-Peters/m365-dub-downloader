## FAQ

**What is Microsoft AI Gateway?**

Microsoft AI Gateway is a set of Azure API Management features that gives AI traffic one control point. Apps, copilots and agents send requests through it to approved models, MCP tools, other agents and business APIs. The gateway applies access rules, limits, safety checks and logging, so each app team does not have to build these controls itself.

**How does Microsoft AI Gateway help control AI token costs?**

It lets you set request limits, token limits and quotas per app, team, project or consumer, for example tokens per minute or a monthly allowance. When a workload hits its limit, the gateway can reject or slow its requests, protecting critical workloads. It also records caller, model and token use, so costs can be traced to their source.

**How should a company get started with Microsoft AI Gateway?**

Start with one real workload, such as a support assistant that already calls a model, and put its model endpoint behind the gateway instead of handing out provider keys. Name an owner, use Entra-based access, set a fitting token limit, turn on logging and add a content safety rule. Then add approved MCP tools one at a time.
