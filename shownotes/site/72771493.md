## FAQ

**Do I still need network security groups if I run Azure Firewall?**

Yes, network security groups remain essential even behind a central firewall. Rex explains that Azure handles routing on each virtual machine or resource, so peered networks behave like one big network. A single routing mistake can let machines talk to each other directly, and NSGs are the first line of defense that stops this.

**What does Azure Virtual Network Manager do?**

Azure Virtual Network Manager centralizes four jobs across many virtual networks: IP address management, connectivity, security admin rules and routing. You can build hub-and-spoke setups and add networks automatically by tag. Security admin rules take precedence over normal NSG rules, and one route table can be pushed to all networks, all deployable with Bicep.

**How do you secure Azure Functions on the network?**

Close the function off from the internet with private endpoints and send its outbound traffic through VNet integration. Routing that traffic via a NAT gateway gives one fixed IP address that third parties can allowlist, while routing it through a firewall lets you log and restrict destinations. A front-end device such as an application gateway can still publish it.
