## FAQ

**What is the difference between Microsoft 365 Copilot, Fabric AI and Azure AI?**

They are three layers of one stack, not competing products. Copilot is the assistant inside everyday apps like Word and Teams. Fabric AI is Copilot applied to data work inside Microsoft Fabric. Azure AI, now called Microsoft Foundry, is the workshop where developers build their own AI tools and agents from scratch.

**Can Microsoft 365 Copilot see files I don't have access to?**

No, Copilot only uses what the signed-in user can already open. It grounds answers through Microsoft Graph, pulling emails, files and meetings you are allowed to see. The catch is oversharing: a document once shared with the whole company can surface in answers, so cleaning up permissions comes before switching Copilot on.

**Do I need an Azure account to use Microsoft Fabric?**

No, Fabric is its own platform and a business analyst can work in it all day without touching Azure. You sign in through a browser, and data is stored in OneLake so every report reads the same numbers. Fabric AI features, however, need a paid Fabric capacity of a certain size and are not on the free trial.
