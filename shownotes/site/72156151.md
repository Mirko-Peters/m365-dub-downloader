## FAQ

**How do Microsoft Graph delta queries work?**

A delta query returns only what changed since your last sync. The first call pages through all items, then hands you a delta link holding an opaque state token. You store it, for example in Azure Key Vault or SQL, and call it next time to receive just added, updated or deleted items.

**Why don't vector databases enforce document permissions?**

Vectors are arrays of numbers with no permission bits or knowledge of who may see them. If a restricted document is the closest semantic match, the store hands that chunk to the LLM, which summarizes it for anyone asking. Security trimming must therefore be built into the retrieval pipeline explicitly.

**What is lazy GraphRAG and why does it matter?**

Lazy GraphRAG builds a small entity graph only when a query needs relational reasoning, instead of extracting relationships from the whole corpus upfront. It takes top vector results, extracts entities from those files, answers, then discards the subgraph. The episode puts the added retrieval overhead at about 10 percent, making GraphRAG affordable.
