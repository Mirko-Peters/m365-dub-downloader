## FAQ

**What happened to Microsoft Syntex and SharePoint Premium?**

Their capabilities now sit under document processing for Microsoft 365, part of AI in SharePoint. The episode traces the path from Project Cortex in 2019 through SharePoint Syntex, Microsoft Syntex and SharePoint Premium, while SharePoint Advanced Management, Backup and Archive became standalone products. Existing models still run, extract and bill.

**Why does missing metadata hurt Microsoft 365 Copilot answers?**

Copilot relies on metadata, permissions and information architecture to find the right context, so untagged files lead it to obsolete or wrong documents. The episode notes that Copilot can now reason over SharePoint metadata such as classification, department and custom tags, which only helps when those columns are actually populated.

**What are the risks of SharePoint skills and autofill columns?**

Skills have no version control, rollback or sandbox, and by default everyone can create one, so a single mistake can change thousands of records. Autofill configurations cannot be reused across libraries and are tested one file at a time. The episode recommends piloting on a low-stakes site and restricting skill creation to designated owners.
