## FAQ

**How do OPC UA machine signals get into Microsoft Fabric?**

An edge layer subscribes to approved OPC UA nodes, publishes events to a local MQTT broker and forwards selected events through Azure IoT Operations data flows or through Azure IoT Edge and IoT Hub. Fabric Eventstream then receives and routes them to Eventhouse for live queries and to the lakehouse for longer history.

**When should you choose Azure IoT Operations instead of Azure IoT Edge?**

Choose Azure IoT Operations when a site needs a shared industrial data layer with a local MQTT broker, OPC UA connectivity and managed data flows across many assets. It runs on Azure Arc-enabled Kubernetes, so you need people who can operate the cluster. Azure IoT Edge suits focused gateway workloads on lighter hardware.

**Why is real-time machine data not enough to answer production questions?**

Telemetry shows what a machine reports, not what it means for the work. A fault event in Eventhouse does not know the active work order, product variant or delivery risk. That context lives in MES, ERP and maintenance systems, which remain the owners, and must be joined using explicit rules and stable identifiers.
