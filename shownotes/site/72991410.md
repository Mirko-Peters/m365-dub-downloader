## Key takeaways

- Azure Bastion is a fully managed service that gives secure RDP and SSH access to Azure VMs over HTTPS, so the VMs need no public IP and no exposed management ports.
- Native Entra ID authentication brings MFA, Conditional Access and Azure RBAC roles to VM logins and removes the need for local accounts and passwords on each machine.
- Choose the Standard or Premium SKU for production, deploy into a dedicated AzureBastionSubnet, remove public IPs and restrict NSGs to the Bastion subnet, starting with your most critical VMs.

## FAQ

**Do Azure VMs need a public IP when using Azure Bastion?**

No, with Azure Bastion your VMs need no public IP and no open RDP or SSH port. Your browser connects to Bastion over HTTPS on port 443, and Bastion opens the RDP or SSH session to the VM over the private network, so the VM only sees traffic from inside the virtual network.

**How do I log into a VM through Azure Bastion with Entra ID?**

You install the AAD login extension on a supported Windows VM and assign one of two Azure RBAC roles: Virtual Machine User Login or Virtual Machine Administrator Login. Entra ID then appears as the default authentication type in the Bastion connect blade, and MFA and Conditional Access apply to the login.

**Is Azure Bastion more expensive than a jump box?**

Not really, once you count admin time. A jump box VM may cost roughly 35 to 50 dollars a month, but patching, hardening and monitoring push the real total past 200 dollars. At the time of recording, Bastion Standard was about 210 dollars a month, which makes it competitive for production.
