## FAQ

**When should I use a measure instead of a calculated column in Power BI?**

Use a measure whenever the number must change when someone filters, slices or clicks a visual. Calculated columns are filled during refresh and stay static, so they suit fixed values such as a customer's full name. Total sales should be a measure, and overusing columns enlarges the model and slows reports.

**What does the CALCULATE function do in DAX?**

CALCULATE evaluates an expression under a temporarily modified filter context. You pass an expression, usually an existing measure, plus one or more filters that override, add or remove conditions, while the original context stays untouched. Paired with SAMEPERIODLASTYEAR, it returns last year's sales next to this year's in one line.

**Why do my DAX time intelligence functions return blanks or errors?**

Usually because there is no proper date table marked as one. Time intelligence functions need a separate table with one row per day covering the full range without gaps. Right-click it, choose Mark as date table and select the date column. A date column inside the fact table rarely works, because it has gaps.
