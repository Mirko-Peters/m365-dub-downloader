## FAQ

**When should I use Azure Logic Apps and when Azure Functions for Microsoft 365 automation?**

Use Logic Apps when you are orchestrating a process map of connectors and steps, and Azure Functions when you are computing results with loops or heavy logic. The episode recommends combining them: the logic app acts as conductor, while functions do the computation, because paying per action in Logic Apps gets expensive at volume.

**How do you stop Microsoft Graph webhooks from failing silently?**

Pair every Graph subscription with a scheduled delta query that reconciles state, typically once a day. Subscriptions can expire or miss events without raising any error, so the delta query asks the source what changed since the last check and catches gaps. The episode describes the cost as negligible compared with weeks of unnoticed data loss.

**How do you migrate from PowerShell scripts to an automation platform without breaking the business?**

Migrate incrementally instead of rebuilding everything at once. Start with an inventory, build foundations such as managed identities, governance and monitoring, then rebuild the most critical automation and run old and new versions in parallel, comparing outputs before cutover. Each later migration goes faster because the patterns and templates already exist.
