## FAQ

**What is a Copilot skill?**

A Copilot skill is a reusable instruction set that turns the AI into a specialist for one repeatable task. It has a name, a description that tells Copilot when to trigger it, and step-by-step instructions. It is not a chatbot you talk to; it activates automatically only when your request matches its trigger.

**Where are Copilot Cowork skills stored?**

Copilot Cowork skills are stored as Markdown files in your OneDrive, in a Skills folder inside a Cowork folder under Documents. You can write a skill in plain text and upload it there, or let Cowork's built-in skill management create the file for you. Cowork then tests trigger coverage, instruction clarity and robustness.

**When should you use a skill instead of a workflow in Copilot Studio?**

Use a skill when the AI needs to think and adapt on a repeatable task, and a workflow when steps must happen in a strict order with approvals. Workflows give guaranteed, deterministic outcomes such as routing a summary to a manager before sending. Instructions, by contrast, are always active and set tone, role and defaults.
