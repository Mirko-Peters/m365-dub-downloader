## Key takeaways

- Out of the box, Microsoft 365 Copilot only sees Microsoft 365 content; Graph connectors, now called [Copilot connectors](https://www.m365.fm/entity/copilot-connectors/?utm_source=podcast&utm_medium=shownotes&utm_campaign=microsoft-graph-connectors-simply-explained), bring external systems such as Salesforce, ServiceNow or Confluence into reach.
- Synced connectors copy and semantically index data into [Microsoft Graph](https://www.m365.fm/entity/graph/?utm_source=podcast&utm_medium=shownotes&utm_campaign=microsoft-graph-connectors-simply-explained), while federated connectors query the source live through the Model Context Protocol and store nothing in Microsoft 365.
- Every connected item needs a correct access control list, and many organizations combine synced connectors for static knowledge with federated connectors for live operational data.

## FAQ

**What is the difference between synced and federated Copilot connectors?**

Synced connectors copy data into Microsoft Graph, where it is indexed and semantically processed; an admin sets them up once for the organization. Federated connectors store nothing in Microsoft 365 and query the source live through MCP, with each user authenticating individually. Synced suits stable content, federated suits constantly changing data like tickets or inventory.

**Can Copilot connectors write data back to systems like ServiceNow or Salesforce?**

No, federated connectors are read only by default, so Copilot can search and fetch data but cannot create a ticket or update a record. This is by design to keep things safe. If you need Copilot to take actions in an external system, the episode points to a different extensibility model called plugins.

**How do I set up a Graph connector in Microsoft 365?**

Open the Microsoft 365 admin center, go to Search and intelligence, then Data sources, and pick one of over 100 prebuilt connectors. The wizard handles OAuth 2.0 authentication, data selection, field mapping to the Graph schema and ACLs. A straightforward setup takes about 30 minutes; then test that only authorized users see results.
