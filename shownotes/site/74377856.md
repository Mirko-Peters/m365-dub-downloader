## FAQ

**How do you give AI coding agents context about a legacy code base?**

Codify what is specific to your team and code base in agent skills and agents.md instructions, Lars says, rather than fine-tuning a model. Models already know popular tools like Nx, lint rules and caching from training, but they cannot know your legacy code, so written team standards and conventions fill that gap for GitHub Copilot or other agents.

**What is Nx and what does Nx Cloud add?**

Nx is a mostly open source, polyglot toolchain for task orchestration in monorepos, with generators, automatic migrations and lint rules for architectural boundaries. Nx Cloud adds paid features such as remote caching, CI tracing, AI autofix for failing tasks and Nx agents that distribute CI work. Open source projects can apply for Nx Cloud for free.

**What is Nx Polygraph and do you need Nx to use it?**

Polygraph is a separate product from the Nx team, and it does not require Nx. It acts as a meta harness for any AI coding agent, letting one session work across multiple dependent Git repositories, open pull requests in each, and record sessions so a colleague can resume them. At recording time it was free during early access.
