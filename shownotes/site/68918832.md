## FAQ

**Why does Microsoft 365 Copilot give wrong or inconsistent answers?**

Usually because the content underneath is disorganized, not because the AI is broken. Copilot follows links, permissions, content types and tags. When hubs sprawl, libraries lack metadata and duplicate copies look equally authoritative, it cannot prove which document is the real one, so it stitches together fragments and guesses.

**Can better prompts fix poor Copilot answers?**

No, prompts only help Copilot see what is already there; information architecture decides whether there is anything reliable to find. Vector search and RAG help with meaning, but retrieval still depends on structure to set scope, semantics to match content, and governance to decide which sources can be trusted.

**How do you structure SharePoint so Copilot can ground its answers?**

Build structure first, then semantics, then governance. Use one enterprise hub with a few chartered functional hubs, content types with fields like owner, effective date and audience, and a single term store. Then configure search verticals and result templates, enforce sensitivity labels and least privilege, and audit sharing with SharePoint Advanced Management.
