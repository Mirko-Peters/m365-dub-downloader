## FAQ

**When should I use SPFx instead of Power Apps?**

Choose SPFx when you need a rich user interface or a full application, and Power Apps for simple forms with basic conditional logic. Siddharth Vaghasia notes that combining data from several sources is much easier in SPFx code. Power Apps avoids code maintenance and React skills, while AI-assisted coding now makes SPFx fast to build.

**How do permissions work when SPFx calls Microsoft Graph?**

SPFx always runs with the delegated permissions of the signed-in user. You declare the required permissions in the solution's manifest, and a SharePoint admin approves them on the API access page in the SharePoint admin center. If the user has no access to data, the call fails; application permissions require a separate backend API.

**Why is my SPFx web part slow and how do I fix it?**

Usually because it makes too many or unnecessary API calls. Open the browser's network tab and check what loads on page load, and look for calls inside loops, such as one call per parent item. Load only what is needed, combine data on the client side, batch requests, and use a React developer extension to spot repeated re-renders.
