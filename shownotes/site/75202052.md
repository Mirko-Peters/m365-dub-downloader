## Key takeaways

- Telemetry is a time-ordered production record that needs sequence, retention and independent readers, while a discrete event is a notice that something changed and someone may need to react.
- IoT Hub message routing is the telemetry data plane into [Event Hubs](https://www.m365.fm/entity/azure-event-hubs/?utm_source=podcast&utm_medium=shownotes&utm_campaign=iot-hub-message-routing-vs-event-grid-why-telemetry-and-events-are-not-the-same-problem), storage and Microsoft Fabric, whereas Event Grid is a notification fabric with at-least-once, unordered delivery that handlers must treat as a prompt to check current state.
- A device disconnect only proves lost cloud visibility, so production conclusions need MES, ERP and asset model context, shared device identity and explicit data contracts across both paths.

## FAQ

**When should I use IoT Hub message routing instead of Event Grid?**

Use IoT Hub message routing for telemetry that needs a time-ordered record, retention and independent readers, sending it to Event Hubs, storage, Service Bus or Cosmos DB. Use Event Grid for discrete notices such as device created, deleted, connected or disconnected, where several handlers need a prompt to react without consuming the full stream.

**Does an IoT Hub device disconnected event mean the machine stopped?**

No. It only proves the cloud lost contact with the gateway. The press may keep running under local PLC control. A handler should check the last telemetry, current device state and MES records for stops or reason codes, and IoT Hub reports connection changes no more often than every 60 seconds, so short drops can be missed.

**Why shouldn't Event Grid be used as a telemetry bus?**

Event Grid delivers at least once and does not guarantee order, so every subscriber would have to handle duplicates, late arrivals and state reconstruction on its own. Routine readings would also trigger thousands of unnecessary workflows, and nobody would own a complete, replayable record of what the machine did before a quality deviation.
