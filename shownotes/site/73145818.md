## FAQ

**How is Global Secure Access different from a traditional VPN?**

A VPN trusts the network tunnel, while Global Secure Access trusts the verified identity. Once inside a VPN, users can reach almost anything on the network. Microsoft Entra Internet Access checks identity, device and risk on every request, and the private access profile for on-premises servers and legacy apps is what truly replaces the VPN.

**How does Conditional Access stop token theft with Global Secure Access?**

A Conditional Access policy that requires the Global Secure Access client makes stolen session tokens useless. In an adversary-in-the-middle attack, a fake sign-in page captures the token after MFA. The attacker's device has no client and is not connected to Microsoft's secure network, so this compliant network check blocks access despite the valid token.

**Which license do I need for Microsoft Entra Internet Access?**

The Microsoft traffic profile is included with any Microsoft Entra ID P1 license, so Microsoft 365 Business Premium customers already have it. The internet access and private access profiles need add-on licenses, around four to five dollars per user per month at the time of recording, or come bundled in Microsoft Entra Suite.
