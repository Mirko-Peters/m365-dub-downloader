## FAQ

**What is the difference between metrics and logs in Azure Monitor?**

Metrics tell you something is wrong, logs tell you why. Metrics are lightweight numbers like CPU percentage collected at regular intervals in near real time. Logs are detailed event records, such as who signed in from where, stored in a Log Analytics workspace and queried with KQL. The episode compares them to a check engine light and a diagnostic report.

**What happens if I still use the legacy Log Analytics agent?**

Your data has stopped flowing, because the legacy Log Analytics agent is fully retired and its back end shut down on March 2nd, 2026. Everyone needs to move to the Azure Monitor agent with data collection rules. The episode calls this migration the number one priority for anyone who has not completed it yet.

**How can I reduce Azure Monitor log costs?**

Move low-value logs out of the analytics tier into the cheaper basic or auxiliary tiers, which cost about 50 and 5 cents per gigabyte at the time of recording. Also set retention per table, use sampling in Application Insights, and add daily caps and budget alerts. Commitment tiers help only with stable, high ingestion.
