## FAQ

**What are Power Apps code apps?**

Code apps are a recent addition to Power Platform that let makers describe an app in natural language and get a polished app built with React or Vue. Carike Botha contrasts them with canvas apps and model-driven apps: citizen developers do not need to know the code, while pro developers can extend it.

**Do Power Apps code apps have to use Dataverse?**

Only when you build them through vibe.powerapps.com, which Carike Botha describes as being in public preview and defaulting to Dataverse without a way to change it. If you build a code app with the GitHub CLI or Claude Code instead, you can connect it to whatever data source you choose, including SharePoint.

**Are Power Apps code apps enterprise ready?**

Carike Botha says yes, because code apps can connect to different data sources, trigger Power Automate flows and are built inside the Power Platform guardrails. Existing DLP policies, connector restrictions and permissions still apply. She adds that Power Apps target internal users, while external-facing scenarios belong in Power Pages.
