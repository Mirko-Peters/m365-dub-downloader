## FAQ

**Why is logic in Liquid templates a governance risk in legacy portals?**

Logic in Liquid templates is a risk because it runs outside standard Dataverse auditing and security roles, so security teams cannot see it. Mirko Peters calls this shadow logic: unversioned snippets, sometimes written by departed consultants, that can expose or filter records independently of table permissions, turning a simple access audit into a manual code investigation.

**What changes for Power Pages users in the 2026 Wave 1 release?**

In 2026 Wave 1, Power Pages users remain contacts but also sync into Dataverse as system users, and web roles map into Dataverse security roles. Microsoft syncs existing contacts and web roles automatically, so sites keep working without a forced migration, but reports, integrations and custom checks built on contact-only assumptions should be tested now.

**Why can't client-side JavaScript enforce business rules on a portal?**

Client-side JavaScript cannot enforce rules because anyone can open the browser developer tools, disable the scripts and submit whatever data they want. The episode warns that backend plugins may treat the portal's high-privilege service account as trusted and skip their checks. Validation and pricing logic belong on the server, behind the Web API and Dataverse.
