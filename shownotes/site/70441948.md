## FAQ

**Why do Microsoft architects get hired faster than cloud generalists?**

Because enterprises pay to reduce governance complexity, not to add tools. The episode argues that the Microsoft stack treats Entra ID as the control plane, so Power Platform, Azure, Fabric and Defender inherit one policy model. Professionals who can consolidate fragmented identity and security systems into that model solve a more expensive problem than infrastructure speed.

**In what order should I take MS-102, SC-100 and PL-600?**

Start with MS-102, then SC-100, then PL-600. MS-102 builds the identity and endpoint foundation, SC-100 adds security architecture on top of it, and PL-600 shows how process automation inherits those policies. The episode stresses that the real value lies in understanding how the three layers integrate, not in the sequence itself.

**What should a Microsoft architect portfolio include?**

It should include design artifacts that prove orchestration thinking. The episode lists a reference Conditional Access framework, a zero trust diagram, a Power Platform governance design, a licensing optimization playbook, an incident response design across Sentinel, Defender and Entra logs, a migration narrative and an AI agent governance framework, published on GitHub or LinkedIn.
