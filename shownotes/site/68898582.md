## FAQ

**What contrast ratios should a Power BI theme meet?**

Text and UI labels should meet the AA contrast threshold, graphical marks like bars, lines and points should never fall below 3:1, and high-risk KPIs should aim for 7:1. Built-in accessible themes are only a baseline, so test the exact foreground and background colors from your report with a contrast analyzer.

**How do I make matrix subtotals stand out in Power BI?**

Declare subtotal and total styles explicitly in the theme JSON instead of relying on defaults. Give subtotals slightly darker text, a semi-opaque background band and a bolder top divider, then escalate again for grand totals. Test at 80% zoom: if a viewer cannot spot subtotals and grand totals in under a second, the theme fails.

**How should slicer states be styled in a Power BI theme?**

Define all four slicer states in the theme JSON: unselected, selected, hover and disabled. Selected needs a distinct background band with AA contrast text, hover should use an outline or elevation change rather than mimic selected, and disabled lowers opacity but stays legible. Add check marks, a reset button and a filter summary.
