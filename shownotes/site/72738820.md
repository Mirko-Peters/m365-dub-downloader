## FAQ

**Is Microsoft Planner an enterprise project portfolio management tool?**

No, according to Erik van Hurck, Planner is a very good task management solution but not an enterprise project management tool. It lacks a program level, risk management, lessons learned and financials. Planner Premium adds Gantt charts, dependencies, baselines and critical path, but portfolio oversight still needs a layer built on top.

**What is the difference between Planner, Planner Premium, Project and To Do?**

Planner covers lightweight task boards, Planner Premium adds full schedules with dependencies, baselines and critical path, Microsoft Project is the powerful desktop tool for complex schedules, and To Do is a personal task list. Erik notes Microsoft announced at Ignite that task management will come together in one Planner experience.

**How should a PMO govern AI access to project data?**

Start from a zero-permission mindset and grant access step by step. Erik warns that AI can see everything a user can, so portfolio data such as other projects' budgets becomes exposed when permissions are too broad. Organizations need a clear understanding of where permission is given before connecting AI assistants to project information.
