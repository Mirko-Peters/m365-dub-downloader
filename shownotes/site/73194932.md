## FAQ

**Why is Copilot alone not an AI platform?**

Copilot is a feature, a conversational interface on top of a language model, not the infrastructure to run agents at scale. Once several teams build agents in different tools, nothing defines agent identities, routes model calls through a gateway or enforces regional policies, so governance debt grows with every new agent and team.

**What is a model gateway for AI agents?**

A model gateway is a single entry point for all AI traffic, so agents call the gateway instead of models directly. It checks the agent's credentials and permissions, enforces policies such as data residency, attributes token costs to each agent and logs every call. Policy changes are made once at the gateway and apply everywhere.

**How should an organization move existing agents onto an AI landing zone?**

Start with an inventory of every agent, its owner, access, data sources and model dependencies, then design the target landing zone. Migrate in waves, beginning with high-risk and business-critical agents, and apply governance first: each agent gets an identity, policies, observability and lifecycle management before it moves. The episode sketches about six months for 300 agents.
