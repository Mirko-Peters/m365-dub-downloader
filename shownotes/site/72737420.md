## FAQ

**Why is Microsoft Graph called the enterprise nervous system?**

Because it connects identity, security, compliance and collaboration signals in one data plane that machines can act on. The episode describes three layers running through Graph: detection through change notifications and continuous scans, evaluation of signals against policies in Entra and Purview, and remediation through Graph APIs, with every action logged and reversible.

**Which Microsoft Graph and agent deadlines in 2026 does the episode warn about?**

The episode names three: the Microsoft Graph Security API v1 retiring in April 2026, the legacy agent registry API becoming unsupported on June 15, 2026, and the Microsoft Graph Toolkit and Graph CLI retiring on August 28, 2026. Agents not re-registered in Agent 365 become inert, so migration planning should start early.

**Where should an organization start with self-healing governance in Microsoft 365?**

Start with one high-risk domain, such as Teams ownership or SharePoint retention, and define its desired state as executable policy. Then build drift detection with change notifications and continuous scans, automate low-risk fixes like assigning a missing owner, run them for about two weeks, refine the policy and expand step by step.
