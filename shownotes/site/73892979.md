## FAQ

**What is an internal developer platform?**

An internal developer platform is a company's self-service front door to approved building blocks for software. A developer makes a short request, and the platform connects the right people, rules, tools and automation behind it. The front door can be a website, a command line tool, an API or a form stored with the code.

**What is a golden path in platform engineering?**

A golden path is an approved, repeatable route for a job teams do often, such as creating a standard web service in Azure. It sets up the repository, pipeline, hosting, identity, secrets and monitoring without dictating how developers write code. Good golden paths also include an escape hatch, a clear process for special cases.

**Is an internal developer platform the same as a portal like Backstage?**

No. A portal can be the screen people use, but the platform also includes the team that maintains it, the agreed standards, the automation and the ways developers interact with it. Tools such as Bicep, Terraform, GitHub Actions or AKS are possible building blocks, but none of them is required for an IDP.
