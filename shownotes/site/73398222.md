Windows 365 Link looks like a small PC but works very differently, and many teams misjudge where it fits. This episode helps IT administrators and decision-makers understand the device, Cloud PCs, Entra ID and Intune, and decide whether shared-desk and frontline scenarios justify a rollout.

## Key takeaways

- Windows 365 Link is a purpose-built access device: the Windows desktop, apps and files run in a Windows 365 Cloud PC, while the box on the desk only connects the user to it.
- Entra ID handles identity, Intune manages the device and the Cloud PC, and Windows 365 provides the workspace, with TPM, secure boot, BitLocker and no local admin keeping the device locked down.
- The device fits shared desks, shift work and contact centers with reliable networks, but not offline, mobile or developer roles, and it does not work with [Azure Virtual Desktop](https://www.m365.fm/entity/azure-virtual-desktop/?utm_source=podcast&utm_medium=shownotes&utm_campaign=windows-365-link-simply-explained).

## FAQ

**Does Windows 365 Link work with Azure Virtual Desktop?**

No. Windows 365 Link connects only to Windows 365 Cloud PCs and does not connect to Azure Virtual Desktop. Both services relate to Windows desktops in the cloud, but they are different Microsoft services, so organizations running Azure Virtual Desktop today should not assume the device will become their access point.

**What do you need before deploying Windows 365 Link?**

Each user needs a Windows 365 license, an assigned Cloud PC and a Microsoft Entra ID account that can sign in, and the location needs dependable network access. The device does not create a Cloud PC on its own, so the episode recommends piloting it at one shared location through a real workday first.

**Can Windows 365 Link be used offline?**

No. Windows 365 Link needs a wired Ethernet or Wi-Fi connection before it shows anything, because the Windows desktop, apps and files run in the Cloud PC. A poor network means a poor session, so people who travel often, work offline or must keep working during outages are better served by a laptop.
