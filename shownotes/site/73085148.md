## FAQ

**What is the difference between canvas apps and model-driven apps in Power Apps?**

Canvas apps start from a blank screen where you place every control yourself, while model-driven apps generate their interface from Dataverse tables and relationships. Canvas suits task-focused apps like inspection checklists or approval forms. Model-driven suits complex data such as customer management or HR records. One solution can combine both types on shared data.

**Do I need Dataverse to build a Power Apps app?**

No, canvas apps can use any connector, including SharePoint lists, Excel files in OneDrive, SQL databases or Salesforce. Model-driven apps are different: they require Dataverse for their core tables, with external data only through virtual tables. The episode suggests starting small on a SharePoint list and moving to Dataverse once data and relationships get messy.

**Can Claude Code build Power Apps apps?**

Yes, according to the episode Claude Code is supported for Power Apps development, though still in preview as of mid-2026. From a terminal you describe a canvas app, and it generates the underlying YAML file and pushes it into your environment. Microsoft does not yet recommend this for production-critical apps, so generated code needs security and accessibility review.
