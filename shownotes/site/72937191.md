## FAQ

**Do I need to be a developer to use Microsoft Agent Builder?**

No, Agent Builder is a no-code tool inside Microsoft 365 Copilot. You open New Agent, describe what you need in the Describe tab, and Copilot generates a name, description, instructions and suggested prompts. The Configure tab then lets you adjust instructions, add knowledge sources and enable capabilities such as image creation.

**When should I use Copilot Studio instead of Agent Builder?**

Switch to Copilot Studio when you need an external-facing agent, data from sources like SQL, Salesforce or an MCP server, or agentic actions such as creating tickets and triggering workflows. Agent Builder handles internal Q&A over Microsoft 365 content, while AI Foundry is aimed at professional developers building custom solutions.

**Can an Agent Builder agent show users documents they cannot normally access?**

No, agents inherit existing Microsoft 365 permissions and get no special access. If a user cannot open a SharePoint document, the agent will not return it to them. Tenant policies also override the interface, so a web content toggle may appear enabled yet not work if an admin has disabled web search.
