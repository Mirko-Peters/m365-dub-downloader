## FAQ

**Can Copilot in Power BI forecast sales or churn on its own?**

No. Copilot reasons over language patterns and cannot run real statistical models, so its forecasts are confident guesses. Reliable predictions come from models such as ARIMA or gradient boosting built in Fabric notebooks. Copilot's role is to interpret the question, route it to the right model and explain the result, including its uncertainty.

**What is semantic link and SemPy used for in Microsoft Fabric?**

Semantic link exposes Power BI semantic models to Python and Spark code through the SemPy library. Data scientists can list tables and measures, read DAX definitions and evaluate measures from a notebook. Predictive models then train on the same business definitions and row-level security as the official reports, which removes conflicting metric definitions.

**Why is hiding a column in a Power BI report not enough for Copilot security?**

Copilot reads the semantic model, not the report layer, so a column hidden only in the report can still feed its answers. Object-level security removes the column for unauthorized roles at the model level, and row-level security filters rows. Both should be tested with real Copilot queries before a model is prepared for AI.
