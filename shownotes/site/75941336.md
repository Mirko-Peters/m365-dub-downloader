## FAQ

**What is SAP S/4HANA in simple terms?**

SAP S/4HANA is an ERP system, the software a company uses to run core operations such as orders, purchasing, inventory, payroll and closing the books. Released in 2015 as the successor to SAP ECC, it runs only on the SAP HANA database, which keeps data in memory and in columns so reporting can happen live.

**What is the difference between greenfield, brownfield and bluefield SAP migrations?**

Greenfield builds a new system from scratch and redesigns processes, brownfield converts the existing system, and bluefield mixes both. Greenfield gives the cleanest result but usually costs most. Brownfield is faster and keeps history but carries old custom code along. Bluefield moves some processes to a fresh model while converting the rest, spreading change over time.

**Does Microsoft Entra ID replace SAP authorizations for S/4HANA?**

No, Microsoft Entra ID handles authentication but does not replace SAP's own authorization rules. It provides single sign-on and multifactor authentication for SAP apps such as Fiori, so users sign in once instead of juggling separate passwords. SAP's authorization rules still decide what each person is allowed to see and do inside the system.
