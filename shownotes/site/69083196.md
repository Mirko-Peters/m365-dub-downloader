## FAQ

**Can the SharePoint Knowledge Agent answer contract questions with citations?**

Yes. In the episode, the agent turns plain questions such as which NDAs expire in the next 30 days into filters on extracted library columns and returns a list where each row links to the exact clause span. It flags ambiguous language instead of guessing, so people verify by clicking the citation rather than rereading the PDF.

**Do contracts have to leave SharePoint for AI extraction?**

No. Document processing reads each file in place and writes values such as parties, effective date, renewal logic and governing law as column updates, not content edits. The audit log records the change under the processing service identity, the file checksum stays the same, and sensitivity labels, retention and permissions remain untouched throughout.

**How should you start with AI contract management in Microsoft 365?**

Start with one library, such as NDAs or MSAs, and a drop-off intake that requires only counterparty and business owner. Name boring columns like expiration date and notice window, apply one extraction model for dates, renewals and parties, give a small group the knowledge agent, and publish a single Power BI evidence view.
