## FAQ

**What is the main difference between SCCM and Intune?**

The main difference is infrastructure: SCCM runs on your own servers, while Intune is a cloud service. SCCM needs domain controllers, SQL servers, site servers, distribution points and management points. Intune only needs an internet connection, manages Windows, macOS, iOS and Android, and uses a profile-based model instead of agents.

**What is co-management between SCCM and Intune?**

Co-management is Microsoft's supported model where one device is managed by SCCM and Intune at the same time. Workload sliders decide which tool owns compliance policies, device configuration, Windows updates, endpoint protection or application deployment. The episode says organizations often use it for 12 to 18 months as a gradual migration path.

**When should I still use SCCM instead of Intune?**

Keep SCCM when you need task sequences for OS deployment, complex application deployments with dependencies, server management or deep custom reporting. The episode estimates Intune covers roughly 80 to 85% of typical device management scenarios, so SCCM or co-management remains the right call for organizations that fall into the remaining gap.
