## FAQ

**Is Copilot in Business Central free?**

The built-in Copilot features are included in the Business Central license at no extra cost. That covers analysis assist, autofill, marketing text, bank reconciliation, map e-document and chat with Copilot. Agents are different: the Sales Order Agent, Payables Agent and custom agents consume Copilot credits, with only a small monthly pool of free credits per tenant.

**How much do Business Central agents cost in Copilot credits?**

Agents are billed per use in Copilot credits: about one credit for a simple answer, two for a generative answer and about five for an agent action such as creating a sales order. Credits can be pre-purchased in packs or paid as you go, and the agent diagnostics permission set shows consumption per task, day and month.

**Can I build my own agent in Business Central without coding?**

Yes, the 2026 release wave introduces the Agent Designer, which lets you create an agent in a sandbox from plain-English instructions. You assign it a profile that defines which data it can see and set its permissions. Developers who need more control can use the AI development toolkit with AL APIs for production-grade agents.
