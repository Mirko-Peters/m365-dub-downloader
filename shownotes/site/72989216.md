## FAQ

**What is the difference between Azure Logic Apps and Power Automate?**

Power Automate is built for business users and simple personal workflows, while Logic Apps targets IT teams and developers with more complex scenarios, bigger volumes and enterprise security and compliance needs. The episode compares Power Automate to a bicycle for getting around the office and Logic Apps to a delivery truck for heavier loads.

**Should I choose the Consumption or Standard plan for Logic Apps?**

Start with Consumption unless you run high volumes. It charges per execution, with the first 4,000 actions each month free at the time of recording. Standard runs on dedicated compute for a fixed monthly price, from around $175, and adds virtual network support and local hosting, which pays off for workflows running thousands of times.

**How do AI agents work inside Azure Logic Apps workflows?**

AI agents can be added directly as steps in a workflow, where they reason, use tools and make decisions. You give an agent a goal, tools and instructions, and it calls connectors, queries databases or asks for human approval. For example, it can handle a mismatched customer address instead of letting the order workflow fail.
