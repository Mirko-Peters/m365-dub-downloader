## FAQ

**How do you add Microsoft Clarity to SharePoint Online?**

You deploy it as a tenant-wide SPFx application customizer. Create a Clarity project, copy its project ID, upload the SPFx solution to the tenant app catalog and enable the extension with that ID. It then runs on every modern page. Afterwards, check the browser developer tools for requests to Clarity to confirm data is flowing.

**Why are SharePoint page views a misleading measure of intranet success?**

Page views show that someone opened a page, not that they found what they needed. A confusing page can even gain views through repeat visits and failed searches. The episode recommends combining SharePoint analytics with search logs, Microsoft Clarity behavior data and Microsoft Graph structure to tell a popular failure from a genuinely useful page.

**What does Knowledge Agent do in SharePoint?**

Knowledge Agent is a Copilot-powered assistant that acts as a UX analyst and governance helper inside SharePoint. In libraries it suggests metadata columns and fills values from file content. On pages it flags outdated content, broken links and content gaps, and drafts FAQ sections from documents. It requires Microsoft 365 Copilot licenses, and humans still approve changes.
