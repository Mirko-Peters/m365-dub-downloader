Hit the limits of the drag-and-drop canvas? This episode explains Power Apps code apps in plain English for pro developers and makers, covering how they differ from canvas apps, how the SDK connects your React code to Power Platform data, and how governance and licensing work.

In this episode

  • 00:00 – Intro: what are code apps?
  • 00:34 – Code apps versus canvas apps
  • 02:15 – Where canvas apps stop and code steps in
  • 04:01 – The developer toolbox: VS Code, CLI, React
  • 06:06 – What the Power Apps SDK does
  • 08:01 – Data sources and connectors
  • 09:31 – Governance and licensing
  • 11:01 – How it all fits together and next steps

Key takeaways

  • Power Apps code apps are written in JavaScript, TypeScript and React in VS Code but still run inside Power Apps with hosting and authentication handled by the platform.
  • The Power Apps SDK generates typed model and service files for Dataverse, SharePoint and other connectors, and DLP and environment policies still apply.
  • Code apps need a Power Apps Premium license and must be enabled per environment by an admin; they extend canvas apps rather than replace them.

Worth quoting
