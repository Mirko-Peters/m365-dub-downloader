Many organizations build agents as smarter chatbots and then wonder why they hallucinate or stall in pilots. This episode is for architects and IT leaders who want to understand how Microsoft Graph, MCP, LangGraph-style orchestration and Agent 365 combine into governed, graph-powered agents that can act safely at enterprise scale.

In this episode

  • 00:00 – Why chat-only agents fail: the context gap
  • 03:07 – Microsoft Graph as enterprise memory and the read/write boundary
  • 09:41 – Tool calling and LangGraph workflows
  • 13:40 – MCP as the standardization layer
  • 17:20 – Graph connectors and Graph Data Connect
  • 24:11 – Supervisor pattern, handoffs, identity and audit trails
  • 42:13 – Agent 365, ownership and data protection
  • 54:26 – Real-world patterns, scorecards and the road ahead

Key takeaways

  • Enterprise agents need context, memory and the authority to act, and Microsoft Graph supplies the organizational context that an LLM alone lacks.
  • Tool calling, MCP and orchestration frameworks such as LangGraph turn that context into governed actions, with supervisor agents coordinating specialists through shared state.
  • Scaling agents requires dedicated agent identities, least privilege, Purview audit and DLP, human approval for high-risk actions and Agent 365 as the inventory and governance control plane.
