Security signals in Microsoft 365 are scattered across Entra, Exchange, SharePoint and Defender, so slow attacks slip through unnoticed. This episode explains Microsoft Sentinel in plain English for Microsoft 365 admins, from SIEM and SOAR to the new data lake, graphs and AI. You will learn how to get started with one connector and one detection rule without a big security budget.

In this episode

  • 00:00 – Why scattered logs leave you blind
  • 01:19 – SIEM: connecting the dots
  • 02:39 – SOAR and playbooks
  • 04:09 – Sentinel in the Microsoft security stack
  • 05:44 – The unified data lake
  • 07:11 – Threat hunting across years of data
  • 08:40 – Graphs, Security Copilot and MCP
  • 10:38 – Getting started and the big picture

Key takeaways

  • Microsoft Sentinel combines SIEM correlation and SOAR automation so signals from Entra, Exchange, SharePoint and Defender become one story instead of scattered alerts.
  • The Sentinel data lake separates cheap storage from compute, making multi-year log retention affordable and enabling hunting for low-and-slow attacks.
  • Start small: enable Sentinel in the Defender portal, connect Entra ID sign-in logs and install one detection rule from the content hub.
