Small businesses and IT teams need customer portals, partner hubs and self-service sites but rarely have web developers to build them. This episode explains Microsoft Power Pages: how it connects to Dataverse, how the Design Studio and Copilot speed up building, how security and licensing work, and where single-page apps and AI agents take the platform next.

  • 09:28 – Licensing and costs
  • 11:01 – Real-world use cases
  • 13:09 – What's next: SPAs, server logic and AI agents

Key takeaways

  • Power Pages is Microsoft's low-code platform for secure, external-facing websites that read and write live business data in Dataverse, unlike marketing sites built with WordPress or Squarespace.
  • Sites are private by default and protected by a web application firewall, CDN, multiple identity providers, table and page permissions, web roles and the Deep Scan security tool.
  • Standalone per-site licensing, a 30-day trial and new capabilities such as single-page applications, server logic and AI agents make it a full web application platform.
