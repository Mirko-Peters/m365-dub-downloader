PowerShell automation breaks the moment real-world IT tickets stop following the happy path. This episode shows Microsoft 365 and Azure administrators how to evolve script libraries into governed autonomous agents with Semantic Kernel, Microsoft Graph and just-in-time identity, cutting resolution times without giving up control.

In this episode

  • 00:00 – Why your PowerShell scripts are becoming a liability
  • 03:45 – Where automation hits its ceiling
  • 07:16 – The authentication paradox and just-in-time tokens
  • 10:37 – Semantic Kernel and Microsoft Graph as reasoning and data layers
  • 20:25 – Wrapping PowerShell as Semantic Kernel plugins
  • 27:45 – Plan, execute, refine: errors and human approval gates
  • 45:05 – Scaling agent fleets with governance and security
  • 56:45 – Measuring agents, the roadmap and the competitive advantage

Key takeaways

  • Deterministic PowerShell scripts handle execution well but cannot reason about messy tickets, so Semantic Kernel adds a reasoning layer that decides when and in which order to call wrapped cmdlets against Microsoft Graph.
  • Autonomous agents need tighter identity boundaries than humans: replace long-lived service principal tokens with just-in-time, task-scoped tokens from a policy engine, managed identities and continuous access evaluation.
  • Design single-purpose functions with precise descriptions and structured returns, let agents propose while humans approve high-risk changes, and roll out in phases from a read-only pilot to a measured, governed agent fleet.
