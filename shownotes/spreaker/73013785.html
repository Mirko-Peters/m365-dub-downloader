Cognitive Services, Azure AI Studio, Azure AI Foundry, Microsoft Foundry: the constant renaming leaves many developers unsure what the platform actually is. This episode explains Foundry resources, projects, the model catalog, agents and the architecture behind them in plain English, for developers who want to build custom AI solutions on Azure, and ends with concrete first steps.

Key takeaways

  • Azure AI Foundry, now Microsoft Foundry, is one unified platform that replaces stitching together Azure OpenAI, AI Search, Machine Learning and other services by hand.
  • A Foundry resource is the security and billing boundary, while Foundry projects give each AI solution an isolated workspace with its own models, agents and knowledge.
  • Agents in Foundry combine instructions, a model from the catalog, tools, knowledge and memory, and new users should skip classic hubs and start with one project and one agent.
