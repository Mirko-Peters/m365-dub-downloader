Machine data can reach the cloud faster than ever, yet a red machine status still does not tell production which order is at risk. This episode follows one OPC UA signal through the edge, MQTT and Azure IoT into Microsoft Fabric for manufacturing IT, OT and data teams. Learn where context belongs so real-time analytics can support real production decisions.

Key takeaways

  • Getting OPC UA signals into Microsoft Fabric is the easy part; the hard part is linking each event to the active order, product, process and resource.
  • Keep source identity, timestamps and quality codes on every event, and use the edge, MQTT and a unified namespace as governed contracts rather than tag dumps.
  • Use Eventhouse and KQL for live investigation and the lakehouse for history, while ERP, MES and maintenance systems keep ownership of the business context.

Worth quoting

“Telemetry describes what a machine reports, while production context explains what that report means in the flow of work.” – Mirko Peters (05:40)

“If a sensor value arrives late or the server reports a bad quality status, hiding that fact creates a clean looking data set that may be wrong. For industrial analysis, an honest, uncertain value beats a false precise one.” – Mirko Peters (15:35)
