AI coding agents can now inspect repositories, change files, run tests and open pull requests, but in a large code base they easily make locally correct yet architecturally wrong decisions. This conversation with Microsoft MVP Lars Gyrup Brink Nielsen is for developers, platform teams and architects working with GitHub Copilot and monorepos. You will learn how developer experience, Nx tooling, caching and codified team standards give agents clean context and keep their output verifiable.

Key takeaways

  • As AI coding agents move from autocomplete to doing development work, the hard problems become context, team standards and verifying that changes are safe to merge.
  • Good developer experience removes friction through shared tooling such as Nx generators, lint rules for architectural boundaries, CI checks and caching that humans and agents both benefit from.
  • Team-specific knowledge can be codified in agent skills and agents.md instructions, while tools like Nx Polygraph extend agent sessions across multiple dependent repositories.
