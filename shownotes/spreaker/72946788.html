Choosing between Azure Virtual Desktop and Windows 365 is harder than it looks once licensing, skills, security and AI-ready endpoints enter the picture. In this episode, IT architects and decision makers hear from Dieter Kempeneers and Dominiek Verham how both platforms differ, which building blocks matter and how to pick the right virtual desktop strategy for their business case.

  • 30:27 – GPUs, Copilot+ PCs and advising the CIO
  • 38:28 – Security, infrastructure as code and monitoring
  • 49:41 – Rapid-fire questions and closing advice

Key takeaways

  • Azure Virtual Desktop offers maximum flexibility and cost-optimization options but requires VDI skills and a solid Azure foundation, while Windows 365 packages the same capabilities as a simpler, per-user licensed service managed through Intune.
  • Profile management with FSLogix, the right storage choice and a lean image strategy, preferably Microsoft gallery images over hand-built golden images, are key to a healthy AVD environment.
  • Security baselines, Conditional Access and device-aware redirection apply to both platforms, so the decision should start from the business use case, and many organizations end up running both.
