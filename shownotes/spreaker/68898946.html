Shadow IT did not die, it automated: Copilot Studio bots, Power Automate flows and broad Graph permissions quietly move data nobody is watching. This episode is for Microsoft 365 security and governance teams who need to bring AI agents under control. You get a reference architecture, an operational playbook and a risk scoring rubric you can run on your top agents this week.

Key takeaways

  • Every agent needs its own Entra Agent ID tied to a blueprint with a named sponsor, conditional access, access reviews and a kill switch; agents running as humans cannot be governed.
  • Replace broad delegated Graph scopes with app roles and site-scoped permissions, and pair Purview auto-labeling with endpoint and browser DLP for AI domains.
  • Route agent egress through Global Secure Access in logging mode first, then allow-list destinations, and score each agent on identity, data, permissions, network, monitoring and life cycle.
