Microsoft calls the same idea agents in one product and skills in another, which leaves many Copilot users confused. This episode explains in plain English what a Copilot skill is, where it lives in Copilot Chat, Copilot Studio and Copilot Cowork, and how beginners can build their first reliable, reusable skill.

Key takeaways

  • A Copilot skill is a reusable instruction set made of a name, a trigger description and step-by-step instructions that runs only when a request matches.
  • Skills live in three homes: Agent Builder in Copilot Chat for no-code creation, Copilot Studio for Markdown files with scripts, and Copilot Cowork for skill files in OneDrive.
  • Good skills have precise names, specific triggers, short instructions, a defined output format and explicit rules, and they improve through testing and iteration.

Worth quoting
