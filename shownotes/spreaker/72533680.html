Most AI pilots stall not because the model is weak but because agents cannot reach the systems that hold the data. This episode gives Microsoft architects a practical guide to the Model Context Protocol, from the wire protocol and C# SDK to Azure deployment, Copilot Studio, Work IQ, A2A and agent identity, ending with a 90-day roadmap to production.

In this episode

  • 02:46 – What MCP is and why JSON-RPC
  • 13:35 – MCP architecture deep dive: handshake and primitives
  • 21:55 – Building your first MCP server with the C# SDK
  • 30:45 – Transports and Azure deployment patterns
  • 45:33 – Copilot Studio and Work IQ as MCP servers
  • 55:42 – A2A orchestration and agent security with Entra Agent ID
  • 65:37 – Reference architecture and the 90-day roadmap

Key takeaways

  • MCP sits above Microsoft Graph, REST APIs and connectors as a standard discovery and capability layer, so one MCP server can serve every agent in the organization.
  • Use STDIO only for local development and streamable HTTP behind Azure API Management with Entra authentication for production; SSE is deprecated.
  • Combine MCP for tools with A2A for agent collaboration, and secure every agent with Entra Agent ID, Conditional Access and Agent 365 from day one.
