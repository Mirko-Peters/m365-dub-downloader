AI can now build Power Apps from a single prompt, but speed without testing and governance creates new risks. Microsoft MVP and MCT Keith Atherton explains for makers, developers and IT leaders how vibe coding, generative pages and code apps change app development. You learn where AI saves the most time and how to keep citizen development safe.

Key takeaways

  • Power Apps is shifting from drag-and-drop to prompt-driven building with generative pages, the vibe experience and code apps, which will reshape the canvas app experience most.
  • The more AI writes the code, the more important solid testing, clear business requirements and human review become.
  • Governance tools such as DLP policies let citizen developers build safely, and understanding the customer's real problem matters more than coding skill.

Worth quoting

“you could be very, very descriptive or you might have a conversation back and forth. But at the end of the day, it's generative AI that's writing the code for you.” – Keith Atherton (21:05)

“I think the more we rely on AI to write the code, the more important is to make sure the testing is solid because if I've not written the code and I just think, well, I hope that works.” – Keith Atherton (38:46)
