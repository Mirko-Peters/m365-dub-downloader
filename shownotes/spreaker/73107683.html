Attackers no longer break in - they log in with stolen credentials, and traditional security tools never notice. This episode explains how Microsoft Defender for Identity watches your on-premises Active Directory with sensors and behavioral analytics. Security and IT admins learn which attacks it catches and how honeytokens and Defender XDR make it even stronger.

Key takeaways

  • Defender for Identity detects identity-based attacks on on-premises Active Directory by learning normal user behavior and flagging deviations rather than scanning for malware.
  • Lightweight sensors on domain controllers feed a cloud service that detects reconnaissance, pass-the-hash, Kerberoasting, golden tickets, DCSync and lateral movement mapped to MITRE ATT&CK.
  • Combined with Defender for Endpoint, Defender for Office 365, Sentinel and Entra ID Protection inside Defender XDR, its alerts become complete attack stories.
