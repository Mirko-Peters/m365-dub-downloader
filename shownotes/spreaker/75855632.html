Most factory dashboards start at the wrong end: they show a temperature or an OEE number, but nobody can explain where the message came from or whether it can be trusted. This episode is for OT and IT architects, data engineers and manufacturing leaders building industrial IoT on Azure. Follow one telemetry message from a PLC through an edge gateway, MQTT and Azure IoT Hub into Event Hubs, storage, Microsoft Fabric and a dashboard people can act on.

Key takeaways

  • A raw sensor reading only becomes manufacturing information when the pipeline preserves its source, unit, quality state and source timestamp and links it to production context.
  • Azure IoT Hub uses MQTT as a managed device connection with per-device identity, fixed topics, QoS 0 or 1 and routing, so it complements rather than replaces a local MQTT broker.
  • Route telemetry by consumer need into Event Hubs, raw storage and Microsoft Fabric, design consumers to handle duplicates and late data, and keep safety-critical control local at the edge.
