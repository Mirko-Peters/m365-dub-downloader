Many SharePoint developers keep rebuilding the same pickers, data calls and controls. In this interview, MVP Siddharth Vaghasia shows developers and architects how SPFx, PnPjs and the PnP React controls speed up secure, performant SharePoint solutions and where SPFx fits next to Power Apps and Copilot agents.

  • 54:20 – Deployment, agents and rapid fire

Key takeaways

  • Before customizing SharePoint, check whether Microsoft or the PnP React controls already provide what you need, and only build custom components when they do not.
  • SPFx solutions run with the delegated permissions of the signed-in user, so request minimal permissions and never put secrets in client-side code; use a backend API instead.
  • With AI-assisted coding, SPFx has become a fast option for rich user interfaces, while Power Apps remains the better fit for simple forms without code maintenance.
