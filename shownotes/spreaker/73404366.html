VPNs were built for a world where everyone worked in one office and apps lived in one data center. This knowledge nugget helps IT and security teams understand Microsoft Entra Global Secure Access in plain English, showing how Private Access and Internet Access replace broad network tunnels with identity-driven, per-app routes and where to start with a focused pilot.

Key takeaways

  • Traditional VPNs start with the network and often grant broader reach than a user needs, which increases the risk of lateral movement and adds routing and support overhead.
  • Microsoft Entra Global Secure Access puts identity at the center: Entra ID and Conditional Access decide, per request, whether a user on a given device may reach a specific private app or internet destination.
  • Entra Private Access replaces broad VPN tunnels with app-specific routes via connectors, while Entra Internet Access applies web, SaaS and AI traffic rules that follow the user anywhere.

Worth quoting

“Global Secure Access isn't one giant tunnel that takes all your traffic to one place. It's a set of guarded routes. Each route has a destination, a set of rules, and a decision about whether you should be allowed through.” – Mirko Peters (14:50)

“Zero trust doesn't mean trusting nobody forever. It means a connection doesn't earn broad permission, just because it comes from a familiar network, a company location, or an encrypted tunnel.” – Mirko Peters (05:44)
