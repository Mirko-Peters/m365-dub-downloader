Windows 365 Link looks like a small PC but works very differently, and many teams misjudge where it fits. This episode helps IT administrators and decision-makers understand the device, Cloud PCs, Entra ID and Intune, and decide whether shared-desk and frontline scenarios justify a rollout.

In this episode

  • 00:00 – What Windows 365 Link is
  • 01:34 – The device and the Cloud PC
  • 04:48 – Sign-in with Entra ID, Intune management and Teams
  • 08:21 – Security by design: TPM, secure boot, BitLocker
  • 11:54 – Who it fits and who should skip it
  • 16:05 – How the parts connect and three questions before rollout

Key takeaways

  • Windows 365 Link is a purpose-built access device: the Windows desktop, apps and files run in a Windows 365 Cloud PC, while the box on the desk only connects the user to it.
  • Entra ID handles identity, Intune manages the device and the Cloud PC, and Windows 365 provides the workspace, with TPM, secure boot, BitLocker and no local admin keeping the device locked down.
  • The device fits shared desks, shift work and contact centers with reliable networks, but not offline, mobile or developer roles, and it does not work with Azure Virtual Desktop.

Worth quoting

“Windows 365 link is a physical device built for one job, connecting you to a Windows 365 cloud PC. That definition matters because the device and the cloud PC are not the same thing.” – Mirko Peters (01:37)

“Intune manages the small link device at the desk while Windows 365 and Intune manage the actual cloud PC where the user works. One is the access point, the other is the working desktop.” – Mirko Peters (06:53)
