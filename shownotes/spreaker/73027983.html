Everyone uses DNS, but few people understand the chain behind a lookup or how Azure takes over the job. This episode explains Azure DNS for cloud admins and beginners: public and private zones, the record types you actually need, delegation and virtual network links. You will know how to move a domain to Azure DNS without breaking your website or email.

Key takeaways

  • Azure DNS is a managed hosting service for DNS zones, so you no longer run, patch or scale your own DNS servers.
  • Public zones serve names to the internet and require delegation at your registrar, while private zones resolve only inside the virtual networks you link to them.
  • Use alias records for Azure resources and recreate every existing record in Azure before switching name servers to avoid outages.
