Many Power Platform apps work but are hard to use because UX is an afterthought. Microsoft MVP and MCT Tchesco Ayih shares with makers and developers how to design user-centric canvas apps, when to choose Copilot Studio agents over apps, and how AI, code apps and governance are shaping low-code development.

In this episode

  • 00:00 – Welcome and guest introduction
  • 01:37 – Path into Power Platform, MVP and MCT
  • 06:19 – Why UX matters in business apps
  • 17:11 – The Power Platform ecosystem
  • 20:03 – Code apps, PCF and Dataverse
  • 25:33 – Copilot Studio: agent or app?
  • 29:06 – AI, prompt engineering and governance
  • 36:28 – Customer stories, community and rapid round

Key takeaways

  • Start Power Apps projects with a designed UI and user journey before adding data and features, and treat UX as an ongoing process refined through user feedback.
  • Use Copilot Studio agents for simple information requests and step-by-step guidance, but build an app when forms are complex or users need request history.
  • AI speeds up low-code development, but developers stay relevant through prompt engineering, verifying AI output and governing AI in the tenant.
