AI coding agents are changing how Power Platform solutions are designed, built and maintained. In this conversation, Microsoft MVP and MCT Nick Doelman explains to makers, developers and consultants what agentic coding really means in practice. You learn how to combine Visual Studio Code, Dataverse and coding agents productively without giving up governance and control.

In this episode

  • 00:00 – Intro: Nick Doelman's journey from Commodore 64 to Power Platform
  • 08:27 – Living in Visual Studio Code: how building on Power Platform changed
  • 13:51 – What agentic coding means: plans, specs, prompts and supervision
  • 23:13 – Code apps, canvas apps and the future of Power Platform
  • 34:46 – Prompt engineering, reusable skills and governance for agents
  • 40:21 – Dataverse as the core of business systems
  • 46:50 – Agentic AI in Power Pages and platform security
  • 51:00 – Advice: keep experimenting and load Visual Studio Code

Key takeaways

  • Agentic coding works best like pair programming: start with a plan and a product requirements document, generate prompts from it and supervise the agent's output with real technical knowledge.
  • Power Platform makers should start working in Visual Studio Code with tools such as the Dataverse MCP server, agent skills, GitHub Copilot and Claude Code, while Dataverse remains the governed data core.
  • Customers should keep control of prompts, skills and agent-generated documentation alongside their source code, and organizations should retest AI tools regularly because capabilities change fast.

Worth quoting

“And that, to me, is an agentic developer these days is more, in a sense, more of a supervisor than an actual coder, but we're still, we still need to have that technical knowledge. We still need to know how the pieces work.” – Nick Doelman (17:42)
