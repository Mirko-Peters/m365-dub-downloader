AI lets anyone build an app in minutes, but who keeps it maintainable and secure? Mirko Peters and Microsoft MVP Reza Niroomand discuss AI-native fusion development, ALM, Git and Terraform for Power Platform makers, developers and architects, plus the tools XRM Tools and PSDataverse.

In this episode

  • 00:00 – Intro and Reza's journey to the Microsoft ecosystem
  • 08:55 – Three generations of Power Platform
  • 16:56 – Scalability and discipline in the AI era
  • 19:37 – Clean architecture and where business logic lives
  • 25:51 – Code, AI and the review challenge
  • 32:06 – CI/CD, Git and Terraform
  • 43:00 – XRM Tools and PSDataverse
  • 57:03 – Rapid-fire round

Key takeaways

  • Power Platform has moved from low-code productivity through fusion development to AI-native fusion, where AI joins the team without eliminating existing roles.
  • AI makes building apps fast, but maintainability, security, architecture and a disciplined ALM with Git as the single source of truth still decide success.
  • Reza Niroomand's XRM Tools brings plug-in and custom API registration into code inside Visual Studio, while PSDataverse uses PowerShell to move large volumes of data reliably in and out of Dataverse.

Worth quoting

“So this does not eliminate the existing roles. You still have the same roles. Instead it changes how they spend their time, basically.” – Reza Niroomand (12:29)

“creating app was not the biggest problem. You could build apps fast, right? It's a lot faster now, of course, but there is a discipline to it. Like how are you going to maintain it? How are you going to secure it?” – Reza Niroomand (17:59)
