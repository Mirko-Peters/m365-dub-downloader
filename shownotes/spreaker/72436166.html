Low-code makes it easy to build apps and portals, and just as easy to expose data to the world by accident. In this conversation, Microsoft MVP Michel Mendes shares his path from SharePoint developer to Power Platform architect and explains how makers and architects can build Power Pages and Power Apps solutions that are secure, scalable and maintainable.

In this episode

  • 00:00 – From Java student in Brazil to SharePoint developer
  • 03:44 – Configuration first: developer skills in a low-code world
  • 05:39 – AI and the shift to code apps
  • 07:38 – Citizen development and successful Power Platform projects
  • 14:15 – Dataverse and Power Pages for external users
  • 20:29 – How Power Pages evolved: solutions, server logic and SPA sites
  • 24:11 – Power Pages security: Web API, table and column permissions
  • 33:08 – AI in daily work, community and career advice

Key takeaways

  • Start with out-of-the-box configuration and move to pro-code only when low-code is not enough, while keeping Dataverse security and governance in place.
  • Use Power Pages for external users on top of Dataverse, and secure the Web API with enabled fields, table permissions and column permissions instead of hiding data in the client.
  • AI speeds up prototypes and bug fixes, but developers remain responsible for review, security audits and spending tokens only where they create real impact.

Worth quoting

“my mentors at that point, they taught me like, hey, you need to think first, and like, does the feature exist? Can you do it with configuration first? If you can't, then we go to Procode Approaches.” – Michel Mendes (04:23)
