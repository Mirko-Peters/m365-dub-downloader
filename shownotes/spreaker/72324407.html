Quantum computers will break RSA and ECC, and attackers are already storing your encrypted traffic to decrypt it later. This episode is for security architects and Microsoft 365 and Azure administrators who need a realistic post-quantum plan. You will learn why cryptographic agility, not a single algorithm choice, decides whether your organization survives the transition.

Key takeaways

  • Adversaries are already harvesting encrypted traffic, so data that must stay confidential for decades is at risk today, long before a quantum computer exists.
  • The real weakness is rigid, hard-coded cryptography; modularity, API abstraction, policy separation and hybrid key exchange make algorithm changes survivable.
  • Start with governance and a continuous cryptographic inventory, then use what Microsoft already ships (SymCrypt, AD CS ML-DSA, Key Vault previews, Edge defaults) for phased PQC adoption.
