Running your own database server means patching, backups and late-night failovers. This beginner-friendly episode explains Azure SQL Database: how the DTU and vCore models differ, which tier to pick, when elastic pools and serverless save money, and how backups and security work by default. You'll know when to choose the managed service and when a virtual machine is the better fit.

  • 07:28 – Backups and high availability
  • 09:31 – Security without the jargon
  • 11:08 – Managed database or virtual machine
  • 12:42 – Beginner mistakes and wrap-up

Key takeaways

  • Azure SQL Database runs the familiar SQL Server engine as a managed service, so patching, backups and high availability become Microsoft's job.
  • Choose between the simple DTU bundle and the flexible vCore model, start small, and use serverless or elastic pools only for intermittent or spiky workloads.
  • Safe settings such as a closed firewall and encryption at rest are the defaults, so your main job is controlling who gets in, ideally with Entra ID.
