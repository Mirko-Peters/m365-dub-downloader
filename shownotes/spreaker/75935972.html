Many tutorials assume you are not on Windows, and that leaves beginners stuck at the first bash command. This episode explains Windows Subsystem for Linux for IT pros and learners in the Microsoft world: what it is, how WSL 1 and WSL 2 differ, how to install it, where it slows down and how it fits into Azure. You will know whether WSL can replace that second machine you thought you needed.

In this episode

  • 01:05 – What WSL actually is
  • 02:41 – WSL 1 versus WSL 2

  • 06:05 – How Linux and Windows share your files
  • 08:04 – What you can do with WSL
  • 09:50 – Where it breaks and what to watch out for
  • 12:18 – How WSL fits into Azure and Microsoft 365

Key takeaways

  • WSL runs a real Linux environment on Windows 10 and 11, and WSL 2 uses a genuine Linux kernel inside a lightweight virtual machine that starts in seconds.
  • Keep project files on the same side as the tools that use them, because crossing the Windows-Linux file boundary is the slow path.
  • WSL is a free local workshop for building and testing, not a production server, and the same Linux and Azure CLI commands carry over to real cloud systems.

Worth quoting

“W s l is a windows feature that runs a Linux environment right on your PC. It does that without a separate virtual machine, and it does it without wiping your drive to install a second operating system.” – Mirko Peters (01:10)
