Adding a shift, a machine or more stock often just moves the bottleneck and creates overtime and late orders. This episode shows production leaders and planners how factory simulation tests changes against real routings, people, buffers and disruptions before the shop floor pays for them, and where ERP, MES, Fabric and AI fit.

Key takeaways

  • Test a production change such as an extra shift, new machine or smaller buffer in a simulation first, because constraints often move rather than disappear.
  • Start with one concrete decision that has an owner, build a baseline that behaves like normal operations, and model qualified coverage, setups, queues and disruptions as ranges.
  • ERP, MES, Microsoft Fabric, Power BI and AI each support the decision, but only a factory model with explicit rules can rehearse how the plant will respond.

Worth quoting

“A machine can run flat out, while the factory creates a bigger queue somewhere else. You haven't removed the constraint, you've moved it.” – Mirko Peters (03:34)

“Simulation doesn't remove uncertainty. It gives that uncertainty a place in the decision before it shows up on the shop floor.” – Mirko Peters (07:45)
