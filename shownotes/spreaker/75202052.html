Machine telemetry and device events both arrive through Azure IoT Hub, but treating them as the same thing either floods workflows with sensor noise or buries urgent signals in a pipeline nobody watches. This episode is for IoT, OT and Azure architects building manufacturing data platforms. You will learn when to use IoT Hub message routing, when to use Event Grid, and how MES and asset context turn signals into trustworthy production decisions.

  • 100:40 – Data plane, control plane, Fabric and Power BI

Key takeaways

  • Telemetry is a time-ordered production record that needs sequence, retention and independent readers, while a discrete event is a notice that something changed and someone may need to react.
  • IoT Hub message routing is the telemetry data plane into Event Hubs, storage and Microsoft Fabric, whereas Event Grid is a notification fabric with at-least-once, unordered delivery that handlers must treat as a prompt to check current state.
  • A device disconnect only proves lost cloud visibility, so production conclusions need MES, ERP and asset model context, shared device identity and explicit data contracts across both paths.
