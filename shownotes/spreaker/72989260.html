Jumping between five screens whenever something breaks? This episode explains Azure Monitor in plain English for Azure beginners and admins, covering metrics, logs, KQL, workbooks, alerts and the 2026 changes, plus practical tips to keep monitoring costs under control.

Key takeaways

  • Azure Monitor is Microsoft's central observability platform: metrics tell you something is wrong, logs in a Log Analytics workspace queried with KQL tell you why.
  • Data flows in from Azure resources, Application Insights, the Azure Monitor Agent (also via Azure Arc), Entra ID and security tools, and is visualized in workbooks and acted on with alerts, action groups and Logic Apps.
  • Migrate off the retired Log Analytics agent, adopt OpenTelemetry, and control cost by tiering logs, setting per-table retention and using sampling and budget alerts.
