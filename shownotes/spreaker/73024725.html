Some workloads simply cannot wait on storage: SAP HANA logs, large simulations and VDI logon storms. This episode explains for Azure architects and IT pros what Azure NetApp Files is, where it beats Azure Files, and how the flexible service level keeps high performance storage affordable.

In this episode

  • 00:00 – Why Azure NetApp Files exists
  • 00:48 – What Azure NetApp Files is
  • 02:05 – Problems regular storage can't solve
  • 03:20 – Use case: SAP HANA
  • 05:09 – Use case: high performance computing
  • 07:05 – Use case: virtual desktops
  • 09:12 – Azure NetApp Files vs. Azure Files
  • 11:06 – Flexible service level

Key takeaways

  • Azure NetApp Files is a first-party, fully managed Azure file service on NetApp technology that delivers sub-millisecond latency and very high throughput over SMB and NFS.
  • Its sweet spots are SAP HANA, high performance computing and VDI profile storage, while Azure Files remains the cost-effective choice for general file shares.
  • The flexible service level decouples capacity from throughput, so you no longer over-provision storage just to get the performance a workload needs.

Worth quoting

“The issue isn't that Azure files is bad. It's a great service for what it's designed to do. But it's optimized for cost. Not peak performance.” – Mirko Peters (02:54)

“Flexible service level changes that completely. It decouples capacity from throughput, two independent knobs instead of one. You decide how much storage you need and separately how much performance you need.” – Mirko Peters (11:44)
