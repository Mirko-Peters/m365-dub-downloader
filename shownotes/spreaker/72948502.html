Learning data science but stuck without clean, interesting data to practice on? This episode explains Azure Open Datasets for beginners, analysts and ML learners: what is in the catalog, how to pull it into Python, Azure Machine Learning or Power BI, and what really costs money. You will be able to grab ready-to-use data in minutes without scraping or cleaning.

  • 13:45 – The cost question: compute and egress

Key takeaways

  • Azure Open Datasets is a free catalog of curated public data, such as NOAA weather, holidays, US Census and NYC taxi trips, that Microsoft cleans, stores in Parquet and keeps refreshed in Azure.
  • You can load the data with the azureml-opendatasets Python package, register it in Azure Machine Learning, connect Power BI through the Blob Storage connector or query it with Synapse serverless SQL and Databricks.
  • The data and its storage are free, but compute, egress and your own storage are not, so keep compute in the dataset's region and sample before you scale.
