Value stream maps are drawn in a workshop and start going stale the moment production moves on. This episode is for manufacturing, operations and data teams who want a map that regenerates itself from ERP, MES, quality and machine events. You will learn how to define the unit of flow, build a shared language and use Microsoft Fabric without inventing false precision.

  • 66:07 – A late order and an invisible queue
  • 88:17 – Microsoft Fabric as the data foundation
  • 105:01 – Knowledge graphs for changing relationships

Key takeaways

  • A value stream map is a snapshot that decays quickly, but it can become a live model when it is regenerated from ERP, MES, quality, maintenance and shop floor events.
  • Shared definitions of states such as released and complete, data contracts and visible confidence markers matter more than refreshing data every second.
  • Microsoft Fabric can provide the governed data foundation, but the process meaning, ownership and decisions still come from manufacturing teams and an explicit product, process and resource model.

Worth quoting

“A traditional value stream map captures a snapshot of the flow at one point in time. Production keeps moving after the workshop wraps and the map starts going stale almost immediately.” – Mirko Peters (01:01)

“But a timestamp doesn't settle what ready for next operation means, who owns that state or whether physical material can move before a quality decision. Sensors are good at reporting signals. They don't negotiate operating definitions. People do.” – Mirko Peters (16:23)
