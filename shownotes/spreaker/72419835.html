Spinning up resources in Azure takes minutes, but doing it securely and repeatably is hard. Azure MVP Maik van der Gaag explains infrastructure as code, Bicep versus Terraform, DevOps culture and how to use AI-generated code safely, for cloud engineers and platform teams.

  • 07:34 – Cloud trends: hybrid and sovereign cloud
  • 10:12 – Cloud transformation mistakes and AI hype
  • 15:25 – Infrastructure as code explained
  • 21:49 – Bicep vs. Terraform, secrets and identities
  • 31:51 – DevOps culture, GitOps and GitHub vs. Azure DevOps
  • 38:08 – AI for infrastructure teams and getting started

Key takeaways

  • Infrastructure as code makes deployments repeatable, reduces typos and helps detect configuration drift compared with manual changes in the Azure portal.
  • Bicep is the simpler Azure-focused choice while Terraform adds multi-cloud reach and state management, so the right tool depends on the team's scenarios and learning curve.
  • AI can write much of the infrastructure code, but engineers must validate and be able to explain every line before it is deployed.
