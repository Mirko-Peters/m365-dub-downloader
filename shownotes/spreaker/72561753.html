Many organizations are building fragile agents without governance, duplicating work and losing track of what runs in their tenant. This field guide is for IT leaders, architects and makers who need to make sense of Microsoft's agent landscape after Build 2026. You get a four-layer model plus practical guidance on Agent 365, Entra Agent ID, Foundry Agent Service and grounding.

Key takeaways

  • Think of Microsoft agents as four layers, experience, agent, runtime and governance, each with different owners and controls, instead of picking products at random.
  • Agent 365 and Entra Agent ID turn agents into governed identities with least-privilege access, conditional access, audit trails and instant revocation, which addresses shadow agents.
  • Start with one well-scoped agent in Copilot Studio grounded in your own data, register it in Agent 365, measure its impact and graduate it to Foundry for scale.
