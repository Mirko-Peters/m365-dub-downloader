Every VM with a public IP and an open RDP port is a target, and jump boxes add their own patching burden. This episode explains Azure Bastion for Azure admins and cloud architects: how it works, what the Entra ID integration adds and which SKU fits your budget. You will know how to remove public IPs and move to identity-based VM access.

Key takeaways

  • Azure Bastion is a fully managed service that gives secure RDP and SSH access to Azure VMs over HTTPS, so the VMs need no public IP and no exposed management ports.
  • Native Entra ID authentication brings MFA, Conditional Access and Azure RBAC roles to VM logins and removes the need for local accounts and passwords on each machine.
  • Choose the Standard or Premium SKU for production, deploy into a dedicated AzureBastionSubnet, remove public IPs and restrict NSGs to the Bastion subnet, starting with your most critical VMs.
