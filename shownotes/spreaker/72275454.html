Power Apps code apps are blurring the line between low-code and pro-code development. This episode is for Power Platform makers, pro developers and IT teams deciding how to build and govern modern business apps. Microsoft MVP Carike Botha explains what code apps are, where they fit next to Copilot agents and how to keep them enterprise-ready.

  • 29:14 – Citizen developer skills and Power Automate
  • 35:01 – Building with AI and the road ahead
  • 40:43 – Rapid fire and community

Key takeaways

  • Power Apps code apps let citizen developers build polished React-based apps with natural language while pro developers extend the same code with tools like Claude Code or the GitHub CLI.
  • Low code does not mean low discipline: licensing, DLP policies, permissions and governance still apply to code apps inside the Power Platform guardrails.
  • Not every problem needs an agent; identifying process steps and real use cases decides whether an app, a flow or a Copilot agent is the right answer.

Worth quoting

“I absolutely love automation because it really helps us get rid of that tediousness of having to do something over and over and over again.” – Carike Botha (04:29)

“pro coders can also use the likes of Claude code or get up CLI and further enhance those apps so it is really that bridge between a low code and a pro code dev in my opinion.” – Carike Botha (09:21)
