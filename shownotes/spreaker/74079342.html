Many organizations still keep identities in on-premises Active Directory while their people work in Microsoft 365. This knowledge nugget helps identity admins understand Microsoft Entra Cloud Sync, how it differs from Entra Connect, what changed in 2026, and how to run a safe, small pilot before deciding.

  • 18:22 – A safe first move for your company

Key takeaways

  • Microsoft Entra Cloud Sync moves most identity sync processing into Microsoft Entra, leaving only lightweight provisioning agents in the local network that connect outbound to the cloud.
  • Multiple agents provide built-in failover and can connect separate Active Directory forests to one tenant, while scoping by OU or security group and provision on demand keep pilots controlled.
  • Entra Connect still fits setups with pass-through authentication, federation, advanced custom rules or specific Exchange hybrid needs, so compare requirements before migrating and never let both tools manage the same objects.

Worth quoting
