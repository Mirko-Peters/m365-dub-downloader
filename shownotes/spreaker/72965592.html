Connecting AI assistants to an ERP used to mean custom APIs, connectors and security workarounds. This Simply Explained episode is for Dynamics 365 users, IT pros and partners who want to understand how the Dynamics 365 ERP MCP server and the analytics MCP server let agents read ERP data and act on it through natural language, and how to try it safely in Copilot Studio or VS Code.

In this episode

  • 00:00 – Why ERP data is hard to bring into AI
  • 00:46 – What the Model Context Protocol is
  • 01:52 – Static vs. dynamic ERP MCP server
  • 03:36 – The analytics MCP server and BPA
  • 05:25 – Real-world use cases from Microsoft and partners
  • 07:25 – How to get started: prerequisites, Copilot Studio, VS Code
  • 09:33 – Roadmap and future direction
  • 11:26 – What this means for users, IT and partners

Key takeaways

  • The Dynamics 365 ERP MCP server exposes finance and operations functions to AI agents through one governed interface, and the dynamic version lets agents work through forms, including customizations and ISV extensions.
  • The analytics MCP server on Business Performance Analytics needs only two tools, get dataset schema and execute DAX query, and combining it with the action server turns insights into ERP actions.
  • Agents inherit the connected user's Dynamics 365 security, but the preview has limits such as a 120-second timeout, so start with low-risk tasks and keep a human in the loop for high-risk actions.
