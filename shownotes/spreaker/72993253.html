If your app runs on a single VM, one crash or traffic spike takes it offline. This episode explains Azure Load Balancer in plain English for admins and developers new to Azure networking, from frontend IPs and health probes to distribution logic and SKUs. You will also learn the common pitfalls and when to choose Application Gateway, Front Door or Traffic Manager instead.

  • 14:00 – Load balancer vs. Application Gateway vs. Traffic Manager

Key takeaways

  • Azure Load Balancer is a layer 4 traffic director: a frontend IP receives traffic, rules map it to a backend pool, and health probes keep failed servers out of rotation.
  • Traffic is spread by a five-tuple hash per flow, and session persistence should only be enabled when an application truly needs it.
  • Use the Standard SKU with at least two backend instances and check NSG rules, probe port and route tables first when probes report unhealthy servers.
